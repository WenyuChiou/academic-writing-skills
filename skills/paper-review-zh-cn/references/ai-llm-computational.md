# AI、大型语言模型、代理人基础与计算审查模块

<a id="trigger-and-scope"></a>
## 触发条件与处理范围

适用于模拟、代理人基模型、耦合计算系统、机器学习模型或代理模型、生成式 AI、大型语言模型生成的资料或受试者、大型语言模型代理人、提示词研究或代理人评估。当计算研究提出特定领域的物理、行为或政策主张时，应载入其他领域模块。

<a id="computational-and-agent-based-models"></a>
## 计算与代理人基模型

追溯来源资料 → 初始化 → 状态与假设 → 演算法或决策规则 → 耦合或更新 → 校准 → 核验或验证 → 情境 → 产出 → 主张。

检查每个代理人所代表的真实世界实体；状态、观察、行动、时序、异质性与决策逻辑；耦合方向、交换变数、更新频率与反馈延迟；基准线、反事实情境、随机重复次数、敏感度、不确定性、软件版本以及可重现性产物。

区分程式码核验、校准、实证验证、预测评估、情境探索、机制表征与真实世界推论。双向耦合并不必然意味着即时交换。

对于具学习能力的代理人，检查状态空间、行动空间、奖励、更新规则、探索机制、参数、收敛或停止准则，以及相较于较简单基准线所增加的能力。

<a id="ml-and-surrogate-models"></a>
## 机器学习与代理模型

检查训练集、验证集与测试集的划分；空间、时间、受试者或设定档泄漏；预处理配适边界；基准线；调参；不确定性；校准；领域转移；需要时的消融实验；以及部署主张是否超出评估设定的范围。

在接受迁移学习术语之前，应先确认实际的来源与目标任务或分布。

<a id="genai-and-llm-studies"></a>
## 生成式 AI 与大型语言模型研究

检查确切的模型识别码与存取日期、相关时的提供商或本机建置、系统与使用者提示词、情境脉络建构、对话状态、抽样设定、执行次数、可用时的种子、剖析器与验证器逻辑、失败情形、重试、选定执行的规则、汇整方式、工作负载、有报告时的成本、隐私、资料保留以及可重现性产物。

将每个作为条件的输入属性对应至产出主张。检验某个模式是否可能源自设定档、标签、提示词分组、问题顺序、共享历史纪录、抽样、筛选或剖析。仅在主张取决于区分这些解释时才要求进行消融实验；否则应陈述其限制。

针对连结至来源设定档的重复合成回应，确认估计目标为边际、成对、重复还是阶层式。切勿将重复生成视为独立的人类受试者。

区分回应信度或一致性、测量品质、分布相似度、任务表现、行为可行性、行为有效性与真实世界通用性。大型语言模型的一致性并非行为有效性，而生成出的合理解释亦非人类机制的直接证据。

<a id="evaluation-and-reporting"></a>
## 评估与报告

检查基准线、人类参照基准、黄金标准标签、外部基准测试、裁判模型或专家评分是否与主张相符。对于将大型语言模型作为裁判（LLM-as-judge）的设计，检查裁判独立性、评分规准、位置与冗长度偏差、校准、一致性，以及需要时的人类裁决。

在正文、表格、图形、补充材料与程式码之间，查核确切的模型、执行、情境、提示词、呼叫与样本数量。未知的执行时间、Token 数、成本、失败情形或保留条件必须维持为未知，而非转化为零。
