# 水资源、CNHS、政策与不确定性审稿模块

<a id="trigger-and-scope"></a>
## 触发条件与处理范围

适用于水资源系统、水文关联人类系统、人地耦合系统（CNHS）、水政策、架构或工具论文、水文综述、模型不确定性或equifinality。针对洪水、淹水、排水、巨灾或水动力学主张，请载入洪水模块。

<a id="coupled-naturalhuman-systems"></a>
## 人地耦合系统（Coupled Natural–Human Systems）

检核稿件是否指明自然、人类与体制实体；状态变数；决策；回馈；时空尺度；经验依据；以及交换的信息。区分单向驱动、双向回馈、共同演化与即时交换。

验证该研究缺口属于经验、概念、方法、模型建立或整合基础。切勿假定每篇 CNHS 或 ABM 论文都存在模型建立上的缺口。

<a id="water-policy-and-decision-support"></a>
## 水政策与决策支援

检核政策定义、管辖权、法律地位、实施途径、行为假设、时机、法令遵循、分配效应、目标与基准的可比性，以及不确定性。对照权威来源查核诸如 `mandatory`、`approved`、`voluntary` 或 `market-based` 等术语。

区分政策设计、模型实施、行为反应、情境结果，以及观察到的现实可行性。要求对称比较，或提出不对称的明确理由。

<a id="framework-and-tool-papers"></a>
## 架构与工具论文

检核需求、先前方法、模块化、互通性、扩充性、重复使用性、验证、示范以及采纳障碍。区分整合新颖性、实作品质、方法学贡献以及领域洞见。

除非最佳化、赛局理论或 ABM 等方法属于陈述问题的相关替代方案，否则切勿硬性要求对其进行固定文献探讨。

<a id="uncertainty-and-equifinality"></a>
## 不确定性与同效性

检核定义、参数与结构来源、数据与观测不确定性、校准或抽样方法、基准、识别性、敏感度、不确定性传递、分解，以及决策相关性。

区分不确定性与误差、同效性与经验等价，以及情境发散度与机率预测。仅在符合分析时才使用 `characterize`、`quantify`、`decompose` 或 `reduce`；切勿因习惯而硬性规定动词。

<a id="water-reviews-and-syntheses"></a>
## 水资源综述与综整

检核研究计划、来源选取、筛选、编码、概念定义、综整逻辑、证据可追溯性、异质性，以及主张处理范围。围绕论文的研究问题或综整设计来组织研究发现，而非强加固定的主题架构。
