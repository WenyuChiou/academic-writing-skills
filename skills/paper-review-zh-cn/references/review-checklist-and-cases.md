# 审稿检核表与证据支持案例

<a id="activation-and-authority"></a>
## 启动条件与权威依据

当提供评分规准、要求依代码分类的审稿，或比较稿件版本时载入。使用现有的 [round ledger](round-calibration.md) 与 [overlay contract](overlay-contract.md)；切勿建立第二套严重度系统。仅要求检查文法并不会触发全篇检核表。以下案例纯属假设，并不为特定稿件提供研究事实、已核实引文或修正方案。

<a id="compact-check-record"></a>
## 简要检核纪录

针对每个选定的准则记录：来源／代码、适用性与权威依据、当前位置或产件、证据、涵盖状态、问题状态，以及最小必要行动。涵盖状态为 `CHECKED`、`NOT_APPLICABLE`、`OUTSIDE_SCOPE` 或 `UNVERIFIED`。已检核的准则仍可能存在未结问题；无法取得的产件并不等于已确认遗漏。使用轮次纪录帐的解决状态。保留「无变更」结果与各项发现；切勿从少数违规清单推论未读文字的涵盖情况。重复利用同等纪录并整合重复出现的征兆，而非制造凑数的意见配额或产出数字品质分数。

当实质比较或分析发生变更时，在现有纪录中追溯被比较的实体、观察单位、测量值或分母、聚合方式、检定以及获支持的主张。选取相关连结（适用时包括配对或选取）；这不是新表单，也不是针对每个句子的检核表。

<a id="conditional-group-code-mapping"></a>
### 条件群组代码对应

当提供的 Ethan 风格评分规准使用这些代码时，以下为简要检核项目，而非取代所提供的原始来源。仅套用相关项目，并区分实际要求与个人偏好。

| 来源代码 | 检核项目 | 界限 |
|---|---|---|
| G1, G2, G4, A1 | 稳定术语；阅读界线上必要的缩写展开与概念意涵 | 切勿重新定义基本术语或轮换技术同义词。 |
| G6-G8 | 清晰易读的图表；充分的说明文字／图例／注记；已对应的子图 | 应结合图表与说明文字一同检视，而非仅看说明文字长度。 |
| G9, G11 | 适用的页码／行号与跨文件项目排序 | 使用实际的投稿要求与已呈现版面的文件。 |
| I1-I3, A2, R2 | 研究缺口、目标、方法、证据与实质回答相符 | 保留概念／方法论文的贡献与合理的相依问题。 |
| M2, M3 | 流程先于需要该流程的推论；符号表示一致 | 方程式紧接着 where 子句并非必然有缺陷。 |
| R3-R5 | 图表增添不同信息；主要发现容易理解且位置连贯 | 次要诊断信息可留在 SM；多个图表可共同回答一个问题。 |
| D2 | 叙明相关的研究设计、数据、模型与验证界线 | 切勿将可修正的错误改称为研究限制，或强求列出每一种限制类型。 |
| F2 | 书目身分与主张支持分开检核 | 未核实存取并非捏造参考文献的证明。 |

除非当前作者／项目或发表管道将其列为要求，否则 G3/G5 用字禁令、G10 行数目标、A3 句子／语步数量、I4/I5 段落位置以及 C1 结论范本仍属来源特有的偏好。切勿从意见数量推论审稿轮次或准备就绪程度、在后期轮次压制新发现的效度问题、冒充审稿人，或在缺乏适用规则的情况下禁止表格注记。

<a id="cases-for-cross-round-review-and-contribution"></a>
## 跨轮次审稿与贡献案例

<a id="1-relocation-is-not-the-requested-clarification"></a>
### 1. 移位不等于所要求的澄清

- **问题：** 审稿人要求提供处理采行百分比的母体与分母。作者将该段落移至方法并回复 `fixed`，但分母仍未载明。
- **触发条件：** 将要求的读者功能与当前产件进行比对。
- **判定：** 移动文字并非其语意已获澄清的证据。
- **最小行动：** 要求提供已核实的分母并在需要处补上；检查相关图表。记录 `OPEN`，若移位本身亦满足了请求中的明确部分，则记录 `PARTIAL`。
- **界限：** 当移位本身确实解决了所要求的顺序或脉络问题时，切勿硬性要求全盘重写。

<a id="2-no-reply-does-not-mean-no-repair"></a>
### 2. 未回复不代表未修订

- **问题：** 审稿意见询问栖地评分测量的是什么。意见未获回复，但新版方法中已定义该评分，且当前图表说明文字亦一致使用。
- **触发条件：** 将缺少回复误认为稿件问题尚未解决。
- **判定：** 应独立于讨论串动态之外，实质验证修订内容。
- **最小行动：** 为稿件记录 `RESOLVED`；仅在该项交付成果有必要时，才另行要求回复。
- **界限：** 若缺乏所需的图表或原始输出，仅检查图表说明文字并不能确立绘制数值的准确性。对于缩图中疑似数字或正负号不符的情况，在回报数值错误之前，应检视原始解析度的标记，并区分印刷符号与相邻线条。若无法进行该项检视或检视结果无定论，请记录为未核实。

<a id="3-a-known-input-difference-is-not-the-whole-contribution"></a>
### 3. 已知的输入差异不等于全部贡献

- **问题：** 某模拟给予 A 组比 B 组更多的资产，随后在未作进一步分析的情况下，将 A 组较大的绝对损失作为主要新发现呈现。
- **触发条件：** 所主张的贡献可能只是实验设定的直接后果。
- **判定：** 追问该分析在已知的输入对比之外还确立了什么：量级、适当的比较、异质性、不确定性或界限。
- **最小行动：** 在现有证据中找出额外的洞见，若未提供则限缩该主张。切勿捏造标准化或新结果。
- **界限：** 符合预期的发现仍可能有用；方法学论文可贡献评估或实作，且没有任何研究必须产出令人惊讶的结果。

<a id="4-a-behavioral-measure-is-not-automatically-a-physical-outcome"></a>
### 4. 行为测量指标不自动等同于实体成果

- **问题：** 调查报告了节水意愿；摘要却将此称为已证实的节水量。
- **触发条件：** 浓缩后的结论改变了测量成果。
- **判定：** 意愿、行动与实体效果是各自独立的主张。
- **最小行动：** 还原所测量的成果并重新检核受影响的摘要；仅在必须保留较强烈主张时，才要求提供额外证据。
- **界限：** 当提供实际测量的实体成果时，予以保留。

<a id="5-screening-can-change-the-retained-population"></a>
### 5. 筛选可能改变保留的母体

- **问题：** 无效的生成纪录在某一群体中被排除的比例较高，但回报的比较仍主张代表所有预期的轮廓。
- **触发条件：** 生成、重试、解析、过滤或遗漏值规则可能会改变进入分析的观察值。
- **判定：** 追踪尝试纪录经由排除至保留纪录的过程，以及比较的实际母体；保留比例不均本身并不能确立选择性偏差的方向或量级。
- **最小行动：** 要求提供无法取得的筛选证据，或将主张限缩至有记录的保留母体处理范围；检查受影响的摘要与图表。
- **界限：** 维持透明且处理范围适当的保留纪录比较。切勿仅因发生排除就要求群体规模相等、捏造遗漏数值，或要求进行新实验。

<a id="6-nondetection-is-not-equivalence-supported-equivalence-is-not-a-defect"></a>
### 6. 未检测出不等于等价；具支持依据的等价并非缺陷

- **问题：** 在没有等价准则或支持性分析的情况下，将不显著的差异描述为两种方法等价的证明。
- **触发条件：** 对于相同、等价、一致或结果未变的主张，超出了所提供比较的支援程度。
- **判定：** 厘清被比较的数量以及该特定主张所需的证据。区分未检测出与在合理界限内的等价。
- **最小行动：** 限缩缺乏支持的主张；在其指标、界限与研究处理范围内，保留具适当依据的等价结论。
- **界限：** 切勿禁用 `similar` 或 `equivalent`、强求特定检定，或推论单一成果上的等价意味着两种方法在整体上完全相同。

<a id="comparison-and-test-reporting"></a>
## 比较与检定回报

针对 V1/V2 阶段工作，请指明确切文件与所使用的接受文字／标记检视。依语意对应相关段落，而非仅依段落编号。区分历史修订、残存问题、新退化问题以及无法取得的证据；切勿将每一处差异皆称为改进，亦勿将作者的编辑归功于技能。

利用这些案例来设计兼具缺陷与无变更对照的新颖跨领域探针。将实际的模型决策与路由／连结检核分开测试。通过静态测试或单次成功的稿件审稿，并不能确立通用的检测率、因果性的技能改进或投稿就绪程度。
