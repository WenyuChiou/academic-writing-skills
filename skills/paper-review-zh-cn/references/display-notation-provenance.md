# 图表展示、符号标记与来源出处审查

<a id="load-this-module-selectively"></a>
## 选择性载入此模块

当稿件在图形或表格中使用了方程式、形式符号、带索引的变数、标准化或汇整序列、综合指标、阴影范围、发散度量、情境摘要或其他衍生数量时，应载入此模块。

切勿仅因稿件包含简单的描述性表格，或是变数、单位与来源已十分明确且未经转换的绘图，就载入此模块。单凭图表文件名称、单一符号或泛泛提及不确定性，本身并不足以构成载入依据。

<a id="build-an-equation-and-notation-ledger"></a>
## 建立方程式与符号标记总帐

针对每个重要符号，记录其定义、单位或尺度、定义域、索引、首次定义位置，以及出现该符号的每个产物。接着查核：

- 同一符号未默默代表不同的变数
- 同一变数未在无明确理由的情况下被赋予相互冲突的符号
- 空间、时间、群组、情境、模型与代理人索引保持明确区隔
- 向量、矩阵、参数、估计值、随机变数与观测值使用一致的符号标记
- 方程式、散文、图形、表格、说明文字、附录与补充材料彼此相符
- 敏感度分析与实作符号标记与方法（Methods）中的定义一致
- 转换后、标准化或无因次量仍可与其来源变数明确区分

切勿为未定义的符号捏造定义。应将其分类为缺失、模糊、冲突或无法核实，并指明解决该问题所需的权限。

<a id="trace-derived-display-quantities"></a>
## 追溯衍生显示量

针对每个非直接报告变数的重要数量，进行以下追溯：

```text
source data or model output -> transformation or equation -> aggregation or normalization -> displayed value -> textual claim
```

在方法（Methods）、方程式、可重现的程式码规则、表格附注或说明文字定义中，必须具备可追溯的依据。检查：

- 分子、分母、基准线、参照群组与标准化范围
- 跨时间、空间、人员、执行、模型或情境的汇整层级与加权方式
- 不确定性定义，包括带状区域显示的是离散度、信赖区间、可信区间、分位数、系集还是敏感度范围
- 缺失值、设限值、零分母以及排除之执行或群组的处理方式
- 省略的模型、事件、群组、情境或分图是否具备陈述明确且站得住脚的理由
- 说明文字是否定义了非显而易见的转换与不确定性，而非仅指出颜色与分图
- 正文是否以相同的尺度与相同的比较基准解读所展示的数量

切勿从视觉外观推断来源出处。若无法取得转换或排除规则，应将该主张标记为无法核实，并将任何要求的修改限定于澄清说明，而非重构分析。

<a id="report-material-failures"></a>
## 报告重大缺失

区分：

- **符号冲突（notation conflict）：** 相同的符号或标签具有不相容的涵义
- **定义缺口（definition gap）：** 符号、转换或不确定性展示缺乏定义
- **来源缺口（provenance gap）：** 展示的数值无法追溯至经授权的来源或规则
- **图表与主张不符（display–claim mismatch）：** 正文断言了展示内容不支援的比较、尺度或不确定性涵义
- **跨产物回归（cross-artifact regression）：** 后续编辑更新了某个产物，但导致方程式、说明文字、补充材料或摘要过时

套用基础严重度与证据状态系统。除非歧义性、可重现性或主张的解读受到实质影响，否则切勿将形式美化类的符号标记偏好列为阻碍项目。
