# 洪水、水动力学与巨灾审查模块

<a id="trigger-and-scope"></a>
## 触发条件与处理范围

适用于洪涝危害或风险、降雨–迳流与淹水链、水动力学、排水或管网–地表耦合、巨灾模型、暴露度、脆弱度、保险、调适或损失。当计算、心理计量或 CNHS 组件支持个别独立的主张时，应载入相应模块。

<a id="study-context-and-model-setup"></a>
## 研究情境脉络与模型设置

区分地理与灾害情境脉络与可重现的模型设置。情境脉络可包括流域、排水系统、历史事件、暴露度与观测资料。方法（Methods）应说明输入准备、边界与初始条件、参数、校准、验证、情境与执行过程。

依读者功能对段落进行分类，而非机械式地根据关键字进行移动。

<a id="hydrology-hydrodynamics-and-drainage"></a>
## 水文、水动力学与排水

检查驱动外力、边界条件、空间与时间解析度、校准与验证事件、守恒特性、粗糙系数或水力参数、管网–地表交换、单向相对于双向耦合、交换变数与更新频率。

精确使用降雨量、流量、水深、水面高程、surcharge与淹水等术语。对照方法（Methods）与图表，查核单位、垂直基准、事件数量与每项声称的模型能力。

<a id="catastrophe-and-flood-risk-models"></a>
## 巨灾与洪水风险模型

追溯危害 → 暴露度 → 脆弱度 → 总体损失（ground-up loss） → 保险、财务、行为或政策结果。检查事件定义、汇整方式、基准线、调适与保险逻辑、不确定性、验证证据，以及模拟损失是否与观测损失混淆。

对于住户或代理人行为，查核社会群体、居住产权、可行行动、暴露度与财务结果之间的对应关系。切勿将输入假设的直接结果视为涌现机制。

<a id="figures-maps-and-events"></a>
## 图表、地图与事件

检查分图完整性、事件与模型数量、标准化、空间范围、解析度、色阶、单位、标签、不确定性、易读性，以及说明文字是否区分观测量、模拟量与衍生量。对照发表处与授权要求，核实修改来源的出处标注。

解释每张图表的主要模式与证据。唯有在分析或引用的证据提供支持时，方可要求提供物理或行为机制。

<a id="claim-and-language-boundaries"></a>
## 主张与语言界线

对于真正的预测或预测性评估使用 `prediction`，对于过程模型的情境产出使用 `simulation`。以相关指标、事件范围、不确定性与应用案例验证优越性主张。

在未保留产生该结果之模型、情境、暴露度、调适与财务假设的情况下，切勿从模拟损失降低推断真实世界风险减少。
