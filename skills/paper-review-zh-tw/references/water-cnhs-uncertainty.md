# 水資源、CNHS、政策與不確定性審稿模組

<a id="trigger-and-scope"></a>
## 觸發條件與處理範圍

適用於水資源系統、水文關聯人類系統、人地耦合系統（CNHS）、水政策、架構或工具論文、水文綜述、模型不確定性或equifinality。針對洪水、淹水、排水、巨災或水動力學主張，請載入洪水模組。

<a id="coupled-naturalhuman-systems"></a>
## 人地耦合系統（Coupled Natural–Human Systems）

檢核稿件是否指明自然、人類與體制實體；狀態變數；決策；回饋；時空尺度；經驗依據；以及交換的資訊。區分單向驅動、雙向回饋、共同演化與即時交換。

驗證該研究缺口屬於經驗、概念、方法、模型建立或整合基礎。切勿假定每篇 CNHS 或 ABM 論文都存在模型建立上的缺口。

<a id="water-policy-and-decision-support"></a>
## 水政策與決策支援

檢核政策定義、管轄權、法律地位、實施途徑、行為假設、時機、法令遵循、分配效應、目標與基準的可比性，以及不確定性。對照權威來源查核諸如 `mandatory`、`approved`、`voluntary` 或 `market-based` 等術語。

區分政策設計、模型實施、行為反應、情境結果，以及觀察到的現實可行性。要求對稱比較，或提出不對稱的明確理由。

<a id="framework-and-tool-papers"></a>
## 架構與工具論文

檢核需求、先前方法、模組化、互通性、擴充性、重複使用性、驗證、示範以及採納障礙。區分整合新穎性、實作品質、方法學貢獻以及領域洞見。

除非最佳化、賽局理論或 ABM 等方法屬於陳述問題的相關替代方案，否則切勿硬性要求對其進行固定文獻探討。

<a id="uncertainty-and-equifinality"></a>
## 不確定性與同效性

檢核定義、參數與結構來源、數據與觀測不確定性、校準或抽樣方法、基準、識別性、敏感度、不確定性傳遞、分解，以及決策相關性。

區分不確定性與誤差、同效性與經驗等價，以及情境發散度與機率預測。僅在符合分析時才使用 `characterize`、`quantify`、`decompose` 或 `reduce`；切勿因習慣而硬性規定動詞。

<a id="water-reviews-and-syntheses"></a>
## 水資源綜述與綜整

檢核研究計畫、來源選取、篩選、編碼、概念定義、綜整邏輯、證據可追溯性、異質性，以及主張處理範圍。圍繞論文的研究問題或綜整設計來組織研究發現，而非強加固定的主題架構。
