# 審稿檢核表與證據支持案例

<a id="activation-and-authority"></a>
## 啟動條件與權威依據

當提供評分規準、要求依代碼分類的審稿，或比較稿件版本時載入。使用現有的 [round ledger](round-calibration.md) 與 [overlay contract](overlay-contract.md)；切勿建立第二套嚴重度系統。僅要求檢查文法並不會觸發全篇檢核表。以下案例純屬假設，並不為特定稿件提供研究事實、已核實引文或修正方案。

<a id="compact-check-record"></a>
## 簡要檢核紀錄

針對每個選定的準則記錄：來源／代碼、適用性與權威依據、當前位置或產件、證據、涵蓋狀態、問題狀態，以及最小必要行動。涵蓋狀態為 `CHECKED`、`NOT_APPLICABLE`、`OUTSIDE_SCOPE` 或 `UNVERIFIED`。已檢核的準則仍可能存在未結問題；無法取得的產件並不等於已確認遺漏。使用輪次紀錄帳的解決狀態。保留「無變更」結果與各項發現；切勿從少數違規清單推論未讀文字的涵蓋情況。重複利用同等紀錄並整合重複出現的徵兆，而非製造湊數的意見配額或產出數字品質分數。

當實質比較或分析發生變更時，在現有紀錄中追溯被比較的實體、觀察單位、測量值或分母、聚合方式、檢定以及獲支持的主張。選取相關連結（適用時包括配對或選取）；這不是新表單，也不是針對每個句子的檢核表。

<a id="conditional-group-code-mapping"></a>
### 條件群組代碼對應

當提供的 Ethan 風格評分規準使用這些代碼時，以下為簡要檢核項目，而非取代所提供的原始來源。僅套用相關項目，並區分實際要求與個人偏好。

| 來源代碼 | 檢核項目 | 界限 |
|---|---|---|
| G1, G2, G4, A1 | 穩定術語；閱讀界線上必要的縮寫展開與概念意涵 | 切勿重新定義基本術語或輪換技術同義詞。 |
| G6-G8 | 清晰易讀的圖表；充分的說明文字／圖例／註記；已對應的子圖 | 應結合圖表與說明文字一同檢視，而非僅看說明文字長度。 |
| G9, G11 | 適用的頁碼／行號與跨檔案項目排序 | 使用實際的投稿要求與已呈現版面的檔案。 |
| I1-I3, A2, R2 | 研究缺口、目標、方法、證據與實質回答相符 | 保留概念／方法論文的貢獻與合理的相依問題。 |
| M2, M3 | 流程先於需要該流程的推論；符號表示一致 | 方程式緊接著 where 子句並非必然有缺陷。 |
| R3-R5 | 圖表增添不同資訊；主要發現容易理解且位置連貫 | 次要診斷資訊可留在 SM；多個圖表可共同回答一個問題。 |
| D2 | 敘明相關的研究設計、數據、模型與驗證界線 | 切勿將可修正的錯誤改稱為研究限制，或強求列出每一種限制類型。 |
| F2 | 書目身分與主張支持分開檢核 | 未核實存取並非捏造參考文獻的證明。 |

除非當前作者／專案或發表管道將其列為要求，否則 G3/G5 用字禁令、G10 行數目標、A3 句子／語步數量、I4/I5 段落位置以及 C1 結論範本仍屬來源特有的偏好。切勿從意見數量推論審稿輪次或準備就緒程度、在後期輪次壓制新發現的效度問題、冒充審稿人，或在缺乏適用規則的情況下禁止表格註記。

<a id="cases-for-cross-round-review-and-contribution"></a>
## 跨輪次審稿與貢獻案例

<a id="1-relocation-is-not-the-requested-clarification"></a>
### 1. 移位不等於所要求的澄清

- **問題：** 審稿人要求提供處理採行百分比的母體與分母。作者將該段落移至方法並回覆 `fixed`，但分母仍未載明。
- **觸發條件：** 將要求的讀者功能與當前產件進行比對。
- **判定：** 移動文字並非其語意已獲澄清的證據。
- **最小行動：** 要求提供已核實的分母並在需要處補上；檢查相關圖表。記錄 `OPEN`，若移位本身亦滿足了請求中的明確部分，則記錄 `PARTIAL`。
- **界限：** 當移位本身確實解決了所要求的順序或脈絡問題時，切勿硬性要求全盤重寫。

<a id="2-no-reply-does-not-mean-no-repair"></a>
### 2. 未回覆不代表未修訂

- **問題：** 審稿意見詢問棲地評分測量的是什麼。意見未獲回覆，但新版方法中已定義該評分，且當前圖表說明文字亦一致使用。
- **觸發條件：** 將缺少回覆誤認為稿件問題尚未解決。
- **判定：** 應獨立於討論串動態之外，實質驗證修訂內容。
- **最小行動：** 為稿件記錄 `RESOLVED`；僅在該項交付成果有必要時，才另行要求回覆。
- **界限：** 若缺乏所需的圖表或原始輸出，僅檢查圖表說明文字並不能確立繪製數值的準確性。對於縮圖中疑似數字或正負號不符的情況，在回報數值錯誤之前，應檢視原始解析度的標記，並區分印刷符號與相鄰線條。若無法進行該項檢視或檢視結果無定論，請記錄為未核實。

<a id="3-a-known-input-difference-is-not-the-whole-contribution"></a>
### 3. 已知的輸入差異不等於全部貢獻

- **問題：** 某模擬給予 A 組比 B 組更多的資產，隨後在未作進一步分析的情況下，將 A 組較大的絕對損失作為主要新發現呈現。
- **觸發條件：** 所主張的貢獻可能只是實驗設定的直接後果。
- **判定：** 追問該分析在已知的輸入對比之外還確立了什麼：量級、適當的比較、異質性、不確定性或界限。
- **最小行動：** 在現有證據中找出額外的洞見，若未提供則限縮該主張。切勿捏造正規化或新結果。
- **界限：** 符合預期的發現仍可能有用；方法學論文可貢獻評估或實作，且沒有任何研究必須產出令人驚訝的結果。

<a id="4-a-behavioral-measure-is-not-automatically-a-physical-outcome"></a>
### 4. 行為測量指標不自動等同於實體成果

- **問題：** 調查報告了節水意願；摘要卻將此稱為已證實的節水量。
- **觸發條件：** 濃縮後的結論改變了測量成果。
- **判定：** 意願、行動與實體效果是各自獨立的主張。
- **最小行動：** 還原所測量的成果並重新檢核受影響的摘要；僅在必須保留較強烈主張時，才要求提供額外證據。
- **界限：** 當提供實際測量的實體成果時，予以保留。

<a id="5-screening-can-change-the-retained-population"></a>
### 5. 篩選可能改變保留的母體

- **問題：** 無效的生成紀錄在某一群體中被排除的比例較高，但回報的比較仍主張代表所有預期的輪廓。
- **觸發條件：** 生成、重試、解析、過濾或遺漏值規則可能會改變進入分析的觀察值。
- **判定：** 追蹤嘗試紀錄經由排除至保留紀錄的過程，以及比較的實際母體；保留比例不均本身並不能確立選擇性偏差的方向或量級。
- **最小行動：** 要求提供無法取得的篩選證據，或將主張限縮至有記錄的保留母體處理範圍；檢查受影響的摘要與圖表。
- **界限：** 維持透明且處理範圍適當的保留紀錄比較。切勿僅因發生排除就要求群體規模相等、捏造遺漏數值，或要求進行新實驗。

<a id="6-nondetection-is-not-equivalence-supported-equivalence-is-not-a-defect"></a>
### 6. 未檢測出不等於等價；具支持依據的等價並非缺陷

- **問題：** 在沒有等價準則或支持性分析的情況下，將不顯著的差異描述為兩種方法等價的證明。
- **觸發條件：** 對於相同、等價、一致或結果未變的主張，超出了所提供比較的支援程度。
- **判定：** 釐清被比較的數量以及該特定主張所需的證據。區分未檢測出與在合理界限內的等價。
- **最小行動：** 限縮缺乏支持的主張；在其指標、界限與研究處理範圍內，保留具適當依據的等價結論。
- **界限：** 切勿禁用 `similar` 或 `equivalent`、強求特定檢定，或推論單一成果上的等價意味著兩種方法在整體上完全相同。

<a id="comparison-and-test-reporting"></a>
## 比較與檢定回報

針對 V1/V2 階段工作，請指明確切檔案與所使用的接受文字／標記檢視。依語意對應相關段落，而非僅依段落編號。區分歷史修訂、殘存問題、新退化問題以及無法取得的證據；切勿將每一處差異皆稱為改進，亦勿將作者的編輯歸功於技能。

利用這些案例來設計兼具缺陷與無變更對照的新穎跨領域探針。將實際的模型決策與路由／連結檢核分開測試。通過靜態測試或單次成功的稿件審稿，並不能確立通用的檢測率、因果性的技能改進或投稿就緒程度。
