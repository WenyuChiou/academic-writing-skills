# 洪水、水動力學與巨災審查模組

<a id="trigger-and-scope"></a>
## 觸發條件與處理範圍

適用於洪澇危害或風險、降雨–逕流與淹水鏈、水動力學、排水或管網–地表耦合、巨災模型、暴露度、脆弱度、保險、調適或損失。當計算、心理計量或 CNHS 組件支持個別獨立的主張時，應載入相應模組。

<a id="study-context-and-model-setup"></a>
## 研究情境脈絡與模型設置

區分地理與災害情境脈絡與可重現的模型設置。情境脈絡可包括流域、排水系統、歷史事件、暴露度與觀測資料。方法（Methods）應說明輸入準備、邊界與初始條件、參數、校準、驗證、情境與執行過程。

依讀者功能對段落進行分類，而非機械式地根據關鍵字進行移動。

<a id="hydrology-hydrodynamics-and-drainage"></a>
## 水文、水動力學與排水

檢查驅動外力、邊界條件、空間與時間解析度、校準與驗證事件、守恆特性、粗糙係數或水力參數、管網–地表交換、單向相對於雙向耦合、交換變數與更新頻率。

精確使用降雨量、流量、水深、水面高程、surcharge與淹水等術語。對照方法（Methods）與圖表，查核單位、垂直基準、事件數量與每項聲稱的模型能力。

<a id="catastrophe-and-flood-risk-models"></a>
## 巨災與洪水風險模型

追溯危害 → 暴露度 → 脆弱度 → 總體損失（ground-up loss） → 保險、財務、行為或政策結果。檢查事件定義、彙整方式、基準線、調適與保險邏輯、不確定性、驗證證據，以及模擬損失是否與觀測損失混淆。

對於住戶或代理人行為，查核社會群體、居住產權、可行行動、暴露度與財務結果之間的對應關係。切勿將輸入假設的直接結果視為湧現機制。

<a id="figures-maps-and-events"></a>
## 圖表、地圖與事件

檢查分圖完整性、事件與模型數量、正規化、空間範圍、解析度、色階、單位、標籤、不確定性、易讀性，以及說明文字是否區分觀測量、模擬量與衍生量。對照發表處與授權要求，核實修改來源的出處標註。

解釋每張圖表的主要模式與證據。唯有在分析或引用的證據提供支持時，方可要求提供物理或行為機制。

<a id="claim-and-language-boundaries"></a>
## 主張與語言界線

對於真正的預測或預測性評估使用 `prediction`，對於過程模型的情境產出使用 `simulation`。以相關指標、事件範圍、不確定性與應用案例驗證優越性主張。

在未保留產生該結果之模型、情境、暴露度、調適與財務假設的情況下，切勿從模擬損失降低推斷真實世界風險減少。
