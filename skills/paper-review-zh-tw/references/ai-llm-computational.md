# AI、大型語言模型、代理人基礎與計算審查模組

<a id="trigger-and-scope"></a>
## 觸發條件與處理範圍

適用於模擬、代理人基模型、耦合計算系統、機器學習模型或代理模型、生成式 AI、大型語言模型生成的資料或受試者、大型語言模型代理人、提示詞研究或代理人評估。當計算研究提出特定領域的物理、行為或政策主張時，應載入其他領域模組。

<a id="computational-and-agent-based-models"></a>
## 計算與代理人基模型

追溯來源資料 → 初始化 → 狀態與假設 → 演算法或決策規則 → 耦合或更新 → 校準 → 核驗或驗證 → 情境 → 產出 → 主張。

檢查每個代理人所代表的真實世界實體；狀態、觀察、行動、時序、異質性與決策邏輯；耦合方向、交換變數、更新頻率與反饋延遲；基準線、反事實情境、隨機重複次數、敏感度、不確定性、軟體版本以及可重現性產物。

區分程式碼核驗、校準、實證驗證、預測評估、情境探索、機制表徵與真實世界推論。雙向耦合並不必然意味著即時交換。

對於具學習能力的代理人，檢查狀態空間、行動空間、獎勵、更新規則、探索機制、參數、收斂或停止準則，以及相較於較簡單基準線所增加的能力。

<a id="ml-and-surrogate-models"></a>
## 機器學習與代理模型

檢查訓練集、驗證集與測試集的劃分；空間、時間、受試者或設定檔洩漏；預處理配適邊界；基準線；調參；不確定性；校準；領域轉移；需要時的消融實驗；以及部署主張是否超出評估設定的範圍。

在接受遷移學習術語之前，應先確認實際的來源與目標任務或分佈。

<a id="genai-and-llm-studies"></a>
## 生成式 AI 與大型語言模型研究

檢查確切的模型識別碼與存取日期、相關時的提供商或本機建置、系統與使用者提示詞、情境脈絡建構、對話狀態、抽樣設定、執行次數、可用時的種子、剖析器與驗證器邏輯、失敗情形、重試、選定執行的規則、彙整方式、工作負載、有報告時的成本、隱私、資料保留以及可重現性產物。

將每個作為條件的輸入屬性對應至產出主張。檢驗某個模式是否可能源自設定檔、標籤、提示詞分組、問題順序、共享歷史紀錄、抽樣、篩選或剖析。僅在主張取決於區分這些解釋時才要求進行消融實驗；否則應陳述其限制。

針對連結至來源設定檔的重複合成回應，確認估計目標為邊際、成對、重複還是階層式。切勿將重複生成視為獨立的人類受試者。

區分回應信度或一致性、測量品質、分佈相似度、任務表現、行為可行性、行為有效性與真實世界通用性。大型語言模型的一致性並非行為有效性，而生成出的合理解釋亦非人類機制的直接證據。

<a id="evaluation-and-reporting"></a>
## 評估與報告

檢查基準線、人類參照基準、黃金標準標籤、外部基準測試、裁判模型或專家評分是否與主張相符。對於將大型語言模型作為裁判（LLM-as-judge）的設計，檢查裁判獨立性、評分規準、位置與冗長度偏差、校準、一致性，以及需要時的人類裁決。

在正文、表格、圖形、補充資料與程式碼之間，查核確切的模型、執行、情境、提示詞、呼叫與樣本數量。未知的執行時間、Token 數、成本、失敗情形或保留條件必須維持為未知，而非轉化為零。
