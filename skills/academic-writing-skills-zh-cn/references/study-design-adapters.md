<a id="shared-routing-questions"></a>
## 共用流程导引问题

针对每种研究设计，皆应询问：观察或产生了什么实体、预期的比较或被估计量（estimand）为何、存在哪些相依性、呈现了何种不确定性，以及该设计允许何种推论。将缺漏的信息回报为问题；切勿默认其采用了常规选择。

<a id="quantitative-observational-and-survey"></a>
## 量化观察型与调查研究

检查抽样底册、纳入与排除标准、遗漏值状况、变项建构、测量品质、估计式假设、相依性、多重性（multiplicity）、效应大小、不确定性、子群体样本数，以及组间差异是否经过直接检定。

切勿直接推论样本数不相等就必然需要独立样本检定。请先判定观察值是成对、巢套、重复测量、加权、丛集或独立，并优先指明被估计量（estimand）。

对于潜在变项或结构模型，应区分测量适配度、结构适配度、标准化与非标准化系数、模型比较、群组不变性以及描述性路径比较。测量品质不佳并非不可报告，但会收窄构念层级的主张。

在题项筛选后，应追溯施测量表 → 保留题项 → 得分意涵 → 使用该得分的主张。删除题项可能会收窄构念，而无需变更原始问卷。题项用词相同并不能证明测量等值；保留的题项组合不同，也不能证明施测了不同的问卷。应将这些问题与结构系数是否可报告或比较分开处理。

针对重复分析，在核对数值之前，应先确认观察单位、执行选取／汇整方式、变异来源、检定对比以及多重比较族群。当相同的原始检定属于不同的宣告比较族群时，不同的调整后 p 值皆可能有效。应区分模型内显著性与直接的组间检定，并区分不显著与等值。对于计数，除数值外亦应比对事件定义：受影响的执行次数、警告事件与失败纪录不可混为一谈。缺乏来源出处属于核实问题，并非证明数值有误。

<a id="experimental-and-quasi-experimental"></a>
## 实验与准实验

检查分派、对照、处置忠实度、声称时的预先注册、流失、干扰、统计检定力、结果衡量时点、估计量、缺失值、多重结果、稳健性，以及因果表述是否与识别策略相符。

将处置效应与机制及探索性次群组发现区分开来。操弄检核与中介变项必须有直接证据。

<a id="qualitative-and-mixed-methods"></a>
## 质性与混合研究方法

检查抽样逻辑、研究者角色、知情同意、资料产生、声称时的饱和度或信息力、编码过程、反思性、反例个案、引文佐证、稽核轨迹以及可转移性。

若研究设计不允许，切勿将主题出现频率转化为母体盛行率。在混合方法中，应指出整合切入点，并说明结合不同研究主线相较于平行报告增加了哪些价值。

<a id="computational-and-simulation"></a>
## 计算与模拟

追溯来源资料 → 初始化 → 假设 → 演算法 → 耦合或状态更新 → 校准 → 验证（validation）或核验（verification） → 情境 → 产出 → 主张。检查基准线、随机重复次数、敏感度、不确定性、参数出处、软件版本以及可重现性产物。

区分程式码核验、实证验证、预测表现、情境探索、机制表征以及真实世界推论。

<a id="ai-and-llm-studies"></a>
## AI 与大型语言模型研究

检查确切的模型识别码与日期、系统与使用者提示词、情境脉络建构、对话状态、抽样设定、执行次数、可用时的随机种子、剖析器与验证逻辑、失败情形、选定执行的规则、汇整方式、工作负载、有报告时的成本、资料保留、隐私以及可重现性产物的发布。

将每个以输入为条件的属性对应至产出主张。检验报告的模式是否可能直接源自提示词条件设定、分组问题、共享设定档、状态泄漏或模型架构。仅在主张取决于区分这些解释时，才要求进行消融实验；否则应陈述其限制。

针对连结至相同来源设定档的重复合成回应，在选取检定之前，应先确认估计目标为边际、成对、重复或阶层式。在缺乏适当比较的情况下，切勿将个别的标准化系数视为相等或差异的正式证据。

当输入设定档改变而人类或其他参照基准维持固定时，
应将观察到的对比归因于该等输入条件下的比较。
这并不能显示参照母体会如何回应改变后的输入，
且在缺乏专门检验该机制的证据前，也不能揭示模型内部机制。

<a id="evidence-synthesis"></a>
## 证据合成

检查研究计划书、检索来源与日期、合格标准、筛选、萃取、偏差风险、合成方法、异质性、相关时的发表偏差、确定性，以及从纳入研究到主张的可追溯性。

围绕问题或合成逻辑组织研究发现，而非随意的主题。区分证据量、一致性、效应大小、研究品质以及缺乏证据的情形。

<a id="theoretical-framework-methods-and-data-papers"></a>
## 理论、架构、方法与资料论文

梳理前提或需求 → 推导或设计 → 示范或评估 → 边界条件 → 贡献。当稿件已提供适当的证明、基准测试、个案示范、易用性评估或概念性论证时，切勿强求传统的实证结果（Results）。

对于架构与资料论文，应区分整合的新颖性、实作品质、验证证据、可重复使用性以及领域影响力。避免在未加限定的情况下，仅凭单一说明性个案就主张具有广泛的实用性。
