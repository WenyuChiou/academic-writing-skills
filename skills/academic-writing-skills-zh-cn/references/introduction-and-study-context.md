## 处理范围与推展顺序

即便稿件采用其他标题，亦请运用本指南来落实「引言」或「研究背景」章节的读者功能。请遵循作者宣告的推展顺序。对于实证文章，一个有用的起始顺序是：引言 → 研究背景 → 方法 → 结果 → 讨论 → 结论 → 从稳定文本重塑摘要。这并非适用于所有文类的必备结构。当后续证据改变了研究能回答的问题时，请重新检视早期的研究定位。

在起草之前，请确认研究目的、设计、目标受众、可用来源以及相关的研究事实。缺失的选取理由、来源支持或处理范围细节，乃是尚待解决的未知数，切勿借机自行捏造。请套用 [universal-integrity.md](universal-integrity.md) 与 [prose-and-citation-editing.md](prose-and-citation-editing.md) 中通用的段落与读者指引规则。

请运用以下功能规划所要求的单元。当不同的逻辑关联更有助于读者理解时，各功能得予合并、分散于数个段落或重新排序。切勿将表格化为死板的四段式范本、强制要求编号的研究问题，或将局部编辑扩大为全篇论文审阅。

<a id="introduction"></a>
## 引言

「引言」确立了为何需要本研究，以及其研究目的是如何从既有知识中推展而来。

| 读者功能 | 起草决策 | 应避免事项 |
|---|---|---|
| 确立问题及其重要性 | 从能直接引导至实际问题的高度展开；指明处于关键的核心理解或决策。 | 宽泛宏大的开头，其与本研究的关联直到很晚才显现。 |
| 确立已知成果 | 依推展论点的关联组织各项研究；利用密切的先例确立哪些问题已被探讨。 | 个别论文的清单盘点，或借由略去重叠工作来制造新颖性。 |
| 指明研究缺口及其重要性 | 指名未解决的知识、比较、母体、尺度或分析层级，及其具正当理由的后果。 | 未加说明的 “remains unclear,”、缺乏支持的 “no study,”，或泛泛的重要性主张。 |
| 陈述研究目的与途径 | 从缺口引出目标或研究问题；提供最低限度的宏观途径以及受证据约束的预期贡献。 | 与缺口无关的问题、实作细节，或超出研究设计所能支撑的过大贡献。 |

在利用概念或制度背景来说明群体差异或提出研究问题之前，请先介绍理解问题所需的相关背景。切勿假设读者已经知晓特定区分为何重要。详细的研究地点描述与可重现的程序，应保留在具备该功能的专门章节中。

当缺口主张描述了当前的研究现况时，请查核文献检索与密切先例是否足够即时，得以支持该主张。较旧的文献来源可确立基础性问题，但无法证明该问题至今仍未被检视。必要时请检索或检视较新且名称不同的文献；否则应限缩该主张并陈述核实界限。切勿强设文献年份截止点，亦不可仅因基础文献年代较久就予以替换。

当提出数个研究问题时，请使它们之间的关联清晰易懂：它们可能是独立、循序或层级关系。检查每个问题是否增添了不同的答案并具备证据途径；指明何时需要某个答案才能回答另一个问题。切勿强求独立性、将单一比较拆成冗余的问题，或仅凭问题顺序便推断因果识别。编号与引言路径导览图仍属作者或发表管道的选择。

在章节处理范围层级，检验读者能否辨识出问题、既有知识、缺失环节、该缺口的后果以及本研究的回应。请将段落的开头与结尾对照阅读：它们应推展论点，而非反复宣称重要性或新颖性。段落层级的任务查核的是其对该推展链的贡献与可用的相邻文本，而非整篇「引言」中的每一项功能。

<a id="study-area-context-and-evidence-setting"></a>
## 研究区域、情境与证据设定

本节确立了诠释研究设计所需的情境设定、采用该设定的理由，以及证据的实际处理范围。本节并非通用的地理或人口百科全书。在非地理研究中，相应的情境设定可能为母体、机构、资料集、实验环境或案例。

| 读者功能 | 起草决策 | 应避免事项 |
|---|---|---|
| 描述相关情境 | 挑选有助于读者理解研究问题或研究设计的地理、社会、体制或抽样背景。 | 在后续研究中毫无作用的背景事实。 |
| 解释选取理由 | 陈述采用该地点、母体、资料集或案例的实际理由，相关时亦包含实际的资料可用性。 | 在缺乏支持证据的情况下，推断所选案例具有理想性、典型性或代表性。 |
| 界定证据界限 | 在诠释所需的层级上，指明实际的空间、时间与母体处理范围。 | 将整个区域等同于分析领域，或将目标母体等同于实际取得的样本。 |
| 为「方法」提供前置条件 | 解释理解后续设定所需的背景概念或体制区分。 | 过早引入参数或演算法，或仅因在此处描述了现实规则，便暗示该规则已被本研究所实作。 |

请区分宏观情境、分析领域或抽样底册，以及实际观察或生成的单元。对于调查研究，相关时应区分目标母体、合格母体或抽样底册，以及实际取得的样本。对于模拟研究，应区分观察到的情境事实与合成指派。选取理由并不能确立代表性或广泛的推论普及性。

相关的体制背景可能超出研究实际实作的范畴。解释其作用时，切勿暗示所有此类规则皆已建立模型或已获强制执行；视需要于「方法」与「研究限制」中说明实际的再现方式与实质省略。在此阶段，背景解释的是为何某项区分至关重要；「方法」解释的则是本研究如何将其操作化。

在章节处理范围层级，检验读者是否知晓相关情境、为何选取该情境、实际研究了什么，以及是否有足够背景理解「方法」。维持经审阅之地图、图表说明、表格与描述的一致性。切勿仅为了结束该章节而添加结果风格的 “so what” 或 RQ 标签。

<a id="first-three-section-handoffs"></a>
## 前三节的交接承接

将「引言」、「研究背景」与「方法」视为读者的推展链：**为何提出此问题 → 采用何种情境与证据处理范围 → 研究如何回答该问题**。请检验各节之间的交接承接，而非机械式遵从三个标题或固定的段落顺序。

| 交接环节 | 查核其关联性 |
|---|---|
| 引言 → 研究背景 | 实际案例或母体是否符合研究问题，且其选取理由是否在未捏造代表性的情况下予以陈述？ |
| 研究背景 → 方法 | 进行该程序所需的概念是否已获介绍，且是否清楚厘清哪些情境事实是测得的、合成指派的，或仅作为背景？ |
| 方法 → 陈述之问题 | 从规划的产出反推，该程序能否在陈述的处理范围与推论层级上，产生研究问题所需的那类证据？ |

透过相关交接环节，追踪实体或单元、概念或结果变数、时空处理范围以及允许的推论。存在差异可能是合理的：例如，外部调查资料可为案例模型提供信息，而无须直接作为被模拟家户的观察资料。请陈述其实际作用与任何转移假设，切勿强求各来源具备完全相同的涵盖范围，亦不可默认它们可以互换。

相同概念在这些章节中扮演不同角色。「引言」解释为何重要；「研究背景」确立其在地相关性与条件；「方法」陈述其实际再现方式、设定参数与实质省略。请简短回溯参照，而非重复完整解释。对于操作性来源出处，请使用 [methods-and-assumptions.md](methods-and-assumptions.md)。

<a id="hidden-mismatch-checks"></a>
## 隐蔽不符之检查

当主张或研究设计使这些问题具备相关性时，请运用它们。它们揭示了可辨识的隐蔽不符形式；但它们并非穷尽未知之未知的侦测器，亦非重写运作正常章节的理由。

| 问题隐匿之处 | 诊断问题与可能的修复方案 |
|---|---|
| 以新标签描述的缺口 | 是否已有密切先例在其他术语下实质探讨了相同的任务？在断言新颖性之前，请先比较实际的研究问题、结果变数、尺度与证据。 |
| 宏大的目的与较狭隘的测量结果 | 研究问题关乎福祉、因果机制或群体行为，而规划的证据却涉及模型化的资产损失或描述性关联？请陈述有依据支持的任务；切勿重命名产出以暗示测量了更广泛的构念。 |
| 案例选取与资料可用性 | 选取方式或缺失的涵盖范围是否限制了所能获知的结论？请回报实际的选取过程与相关界限；切勿凭空捏造偏差、宣称无效，或仅凭涵盖范围便主张代表性。 |
| 地图或情境百分比 | 基于面积的数量是否被误用作基于家户或人口的数量？请指明任何映射或指派假设，而非默默将这些单元划上等号。 |
| 体制背景转变为模型主张 | 规则的条件是否得以保留，且读者是否知晓本研究究竟是再现了资格、法规遵循、强制执行，还是皆无？若简化再现的角色与界限明确，该再现即可具备正当性。 |

当出现不一致时，应找出确切缺失的环节、解决该问题所需的来源，以及获授权的最小幅度修复。若解决问题需要新资料、变更研究问题或更换不同模型，应标记该项决定，而非借由文字叙述暗中补足。

<a id="placement-and-revision-checks"></a>
## 配置与修订检核

应依内容的功能配置内容，而非仅凭其主题：

- 理解研究问题所必需的背景 → Introduction（绪论）；
- 个案特定脉络与实际证据的处理范围 → 研究脉络或对应的情境章节；
- 设定指派、参数、资料转换、抽样程序与演算法 → Methods（方法）或该文类的程序章节。

同一概念可能因不同目的出现在多个章节中；无须每次都重复其完整说明。若特定文类或发表园地将这些功能整合于不同标题下，应予尊重。

对于新草稿，在决定段落界线前，应先规划各项功能与证据。对于已获接受、已投稿或经指导教授编修的草稿，应找出缺失或错置的功能，并进行最小且有依据的修复。切勿仅为了符合本指南而重构运作良好的段落。若内容必须搬移，请指明其目标位置，并检核受影响的转折与参照。

使用 [lifecycle-and-routing.md](lifecycle-and-routing.md) 进行处理范围与变更影响检核。研究缺口或研究问题的变更可能会影响证据链与摘要；局部的语法修复并不代表有权重写这些内容。
