# 修订所要求的批注处理范围

此程序适用于由 Word 批注、标注或选取文字所驱动的编辑。它适用于各类研究设计。选取范围限制了默认的**编辑**处理范围，而非必须**阅读**的脉络范围。既有的最小变更原则依然适用；新增附注或完全无误的扫描并无法证明已遵循这些原则。

<a id="establish-the-current-target-before-drafting"></a>
## 在起草前确立当前目标

1. 确认最新经作者/指导教授核准的文件、其 SHA256、生效的修订措辞以及实际的批注选取范围。连同周围的散文一并阅读完整的批注与回复讨论串。切勿以包含该处的整段文字取代选取范围、仅从批注文字推断目标，或重复使用旧快照的 ID 或定位点。在任何来源变更后，请重读定位锚点。
2. 记录精简的边界：选取文字/定位点、所要求的动作、未变更的周围文字，以及任何明确更广泛的指示。带有 “revise this section” 的标题锚点属于章节层级的授权，而非仅限标题的工作。回复隶属于其既有讨论串；它不会自动成为另一个独立需求。请阅读任何新的说明厘清，而非直接舍弃。
3. 区分提议措辞、编辑文件、撰写回复与解决批注的权限。即使批注本身建议进行修订，“Discuss first,” “do not edit,” 或 “no reply/resolution” 仍然具有约束力。当当前文字已满足需求时，局部维持不变的答复是有效的。

选填且唯读的 `scripts/inspect_comment_targets.py DOCX` 回报快照杂凑值、批注文字/讨论串连结、选取的 XML 文字、段落脉络与定位锚点诊断。使用 `--expected-sha256 HASH` 来剔除过期的快照。请阅读其具体产出；仅知道指令或语言扫描未发现相符项并不能算作定位锚点验证。此辅助工具不是已注册的配接器操作；使用者端需要明确的支援。它绝不会进行编辑、回复、解决问题或授权。

其偏移量描述的是 XML 文字投影，而非 Word Range 位置、行号或呈现后的视图。`range` 标识出可读取的选取范围，而非重写它的核准。`point` 需要脉络与该指示的处理范围。仅含删除或已删除的定位锚点、缺失的端点/定义、多个定位锚点与未解决的讨论串仍属不确定状态。切勿默认选取邻近句子。协调重叠的选取范围，并保留跨段落选取范围的每个部分；两者皆不意味着整份文件已解除锁定。功能变数、绘图、巢状段落与不支援的结构可能需要专门的文件编辑器或检查。

<a id="make-the-smallest-sufficient-revision"></a>
## 进行最小且充分的修订

保留目标之外可用的作者/指导教授措辞以及既有已接受的编辑。即使在选取范围内，亦应保留已发挥其功能的句子；其边界并非改写每个被选取单字的指示。切勿仅为了追求统一风格或通用范本而重写引言、图表说明、评分定义、方法／补充材料（SM）的指引或相邻句子。无论在选取范围之内或之外，皆应保留既有的读者功能。必要的技术性重复并不代表获准重新命名术语。

仅在有明确更广泛的需求，或经证明的事实、交叉参照、文法或逻辑相依性时才扩大范围。找出受影响的相邻内容，说明若不处理该局部修改将会出现何种错误或难以阅读，并仅变更该相依项目。切勿单独将 “improving flow” 作为证据。尊重具体锁定的相邻内容：提出所需的变更并将该相依性标记为未解决，而非直接覆写。重读每个受影响的句子对与段落边界。

指导教授过去的范例提供的是风格或论点结构，而非研究事实。请使用当前的数值、分组、测量指标与合适的措辞；切勿将旧数值、因果强度或未执行的分析复制到当前稿件中。当数值结果需要解读时，将有支持依据的比较连结至其含义与相关问题，而不添加未要求的解释。

<a id="verify-the-exact-candidate-and-report-the-actual-change"></a>
## 验证精确的候选文字并回报实际变更

<a id="test-concern-closure-separately-from-edit-completion"></a>
### 将疑虑解决测试与编辑完成度分开检验

在现有的批注帐则或行内发现中，保留原始来源版本与选取范围、完整的疑虑内容、精确的当前措辞及其定位点，以及该措辞为何能或不能解答该疑虑的理由。将原始选取范围与包含该处的段落以及新的选取范围分开处理：后续的改写可能会移动范围或改变其 ID 所选取的内容。该范围标识了目标；周围的散文则可能提供答案。

在确认批注已解决之前，先重述不熟悉背景的读者必须能够理解的内容，然后在当前的阅读单元中定位该答案。针对逻辑批注，应询问原本的误解是否仍可能合理产生，而非仅看句子是否已被重写。仅命名群组或分类规则，未必能解释其比较为何重要；连接词或更正的地名未必能补足缺失的研究依据。当研究发现看似冲突时，在推断存在矛盾或已成功修复之前，应先区分产出结果、群组、分析层级与检定。

在同一记录内运用有根据的评估：

- **已解决：** 当前可用的措辞回答了该疑虑的每一个部分；有充分理由维持不变亦属合格。请引用该答案，而不仅仅是回复。
- **部分解决：** 同时指出已回答的部分以及仍留给读者的疑问。切勿将整个讨论串回报为已完成。
- **未解决：** 所需的关联或更正仍缺失或不正确。
- **无法核实：** 指出缺失的来源/选取范围/脉络以及无法评判之处。即使未声明其原始文件定位锚点已核实，仍可依据引用的批注来检查显见的文法更正。

这些是疑虑评估，而非新的稿件状态或 Word 解决动作。针对部分解决、未解决或必要的无法核实疑虑，请将帐则状态保持为 `OPEN`；仅在答案已核实时才使用 `RESOLVED`，且仅在既有的权威契约下才使用 `WAIVED`。分组回复必须保留每个子疑虑的涵盖面。应将此判断与编辑/格式保留、字数检查、语言扫描以及独立读者证据区分开来。保留已有成效的修改，而非为了展现工作量而重新改写。请参阅
[evidence-context case 13](evidence-context-cases.md#13-a-rewrite-is-not-concern-closure)。

在选取范围层级比较来源与候选版本。识别哪些句子发生变更，以及哪些周围措辞保持完全一致。纳入任何必要的扩展及其证据；若仅保留了主题，切勿声称段落未变更。即使候选版本文笔流畅，若带有未经说明的超出处理范围变更，亦应予以驳回。维持不变的候选版本仍必须回答实际的需求。

接着检查修复后的单元是否保留其读者导向、正确的数值与含义、内部/邻近连结以及对该问题适用的答案。这些属于内容检查，而非要求添加 SQ 标签或结尾范本。切勿仅为了在选取范围之外获得零差异而保留已损坏的相依性。

针对实际的 DOCX 编辑，亦请使用文件技能检查已储存的修订视图、既有的修订者、批注/回复关系以及可用的指导教授修改。绝不可为了图方便而压平段落、接受所有变更或解决讨论串。单纯文字相同并不能证明元数据或视觉效果已被保留。缺失的检查仍属未核实。若仅获准提出提议，请回报提议内容及其精确差异；切勿暗示来源文件、回复或已解决状态已发生变更。

<a id="hypothetical-local-repair"></a>
### 假设性局部修复

Source: “Figure 4 compares the two groups. Scores use a 0–100 scale. **Group A
averaged 84.6 and group B 78.2. The difference is 6.4 points. This indicates higher
reported willingness in group A.** The instrument is described in Text S3.”

假设仅选取了粗体文字，作者要求连结结果与含义，且当前来源支持这些事实。一个充分的提议为：“Group A reported greater willingness than group B, with mean scores of 84.6
and 78.2, respectively, a difference of 6.4 points.” 开头两句与结尾的补充材料（SM）指引须完全保留。切勿增添实际购买行为、因果关系、显著性或旧范例的数值。此范例并非规定的句子形式，亦非任何真实问卷的证据。
