<a id="functional-transitions"></a>
## 功能性转折

辨识引导读者从一个句子或段落衔接至下一个句子或段落所必需的逻辑关联：对比、延伸、限定、原因、结果、比较、回归本研究，或是衔接至下一节的桥梁。尽可能透过主词与动词表达该关联。仅在转折词能让逻辑关联更清晰时才使用转折词。

摒弃仅宣示思维推进的转折，例如无具体说明的 `Moreover`、`Taken together` 或 `One line of work`。唯有在移除该转折会遮蔽真实逻辑关联时，转折才具有功能性。不要要求每个句子都以连接词开头，且当实质内容句即可承载该关联时，不要额外增加纯粹作为转折的独立句子。

将句首框架（如 `Beyond X,`）视为语境检视的提示，而非默认的论述推进信号。仅在 `X` 明确指出了下一个子句真正有所延伸的边界时，才保留这些句型。若该句仅是增加另一种应用或证据类型，请直接陈述该内容，而不要刻意宣告论述的推进。

在段落交界处，请将前一段的结尾句、修改段落的起始句与结尾句，以及下一段的起始句作为一个完整序列连贯阅读。确认修改后的段落发挥了自身的功用，且未过早承接下一段的工作。当段落衔接至编号的研究问题或目标时，请确切指明每个结尾片语是在为哪一个具体问题做铺陈；不要依赖泛泛的研究缺口句。

在结果（Results）以外的部分也应套用相同的逻辑关联检验。文献分组必须确立目前仍欠缺的具体比较；背景必须为后续的设计选择做铺陈；讨论（Discussion）中的意涵必须紧扣所报告的发现；限制条件必须明确指出受其约束所影响的推论。这些是面向读者功能的范例，而非硬性规定的章节范本。若逻辑关联已很明确，请予以保留。若欠缺证据，应揭示该缺口，而不是捏造一个听起来言之凿凿的过渡桥梁。

当文献段落包含多个范例时，应选择有助于推进论点的证据排序，而非保留最初找到文献的顺序。一个实用的默认排序是：广泛的领域背景、接着是更具体的应用、再到与本研究最直接可比的前人先例，最后是尚未解决的研究缺口。若按时间、方法、因果或对比排序能更好地契合段落功能，则应改用这些顺序；不要将由广到狭的推进顺序强加在具有其他清晰关联的证据上。

若文献的主张能被准确陈述，可将具有相同证据功能的来源整合在同一个句子或子句中。当使用 `For example` 能厘清从宽泛主张走向具体证据的过渡时，可用它来引出代表性文献集，但不要在每次引用前都重复使用举例标记。若最相近的前人先例确立了比较的边界，请将其置于研究缺口的正前方。作为诊断方法，可暂时移除文献引用：剩下的正文读起来仍应是一段层层推进的论证，而非一篇篇研究摘要的条列清单。

<a id="workflow-handoff-test"></a>
### 工作流程衔接检验

对于说明流程的段落，在修订局部批注后，应检视完整的目标单元及现有的边界语句。在顺序或依赖关系至关重要处套用此检验；概念上的比较或文献综合则毋需硬性改写为流水线流程。依据修改幅度调整阅读范围：标点符号的编辑毋需重新审视无关的章节，但修订段落的开头可能会影响其与相邻段落的衔接。

1. 辨识各段落面向读者的功能。顺着步骤追踪信息流：有哪些可用资源、什么操作使用了它、产出了什么，以及该输出接着在何处被使用。当读者需要的是操作流程时，仅列出组件清单是不够的。
2. 检查每一组受影响的相邻句子。陈述第二句增加了什么，并在正文本身中指出其与第一句的连结。解决不明确的执行主体、指涉对象、前置条件或未加说明的换主词情况。在每个段落交界处，检查前一段结尾是否为下一段开头做好铺陈；若某项细节的位置打断了该连结，请予以挪动。当开头已具备过渡衔接时，切勿添加多余的过渡句。
3. 区分初始的使用者配置与执行过程中的重复动作。例如，选择模型接收哪些变数，与在每个时间步更新其数值是不同的。当混淆两者会错误描述使用者工作流程时，应明确指出执行者与频率。若来源未确立这些信息，应记录该缺口，而非凭空捏造手动操作、自动化或执行时程。
4. 保留真实的分支情况。区分循序步骤、可选的增补项、推进的前置条件、诊断性评估，以及改变或终止执行的操作。切勿将资料依赖性转变为同时执行、将诊断转变为自动否决，或将时间顺序转变为因果关系。应根据所提供的方法确立这些事实；范例无法提供缺失的实作证据。
5. 依据有支持的关联来选择连接词。`Then` 可标示后续步骤；`once` 或 `after` 可标示前置条件；`if` 则引入条件。在有助于读者理解时应予以保留。避免硬性规定连接词配额、机械性替换同义词，或在每个句首皆放置连接词。
6. 以一般研究人员的步调阅读最终文字，并仅凭内文转述该路径。检查目标领域的读者在不知晓起草讨论的情况下，能否辨识输入项、操作、输出项及分支后果。修订剩余的最小阻碍，并在最终字词修改后，重新阅读受影响的部分。

<a id="worked-example-daily-forecasting"></a>
#### 实作范例：每日预报

这是一个假设性的教学范例，并非针对实际套件的主张。假设来源确立了以下事实：使用者在执行前选择输入变数；变数数值每日更新；预报使用完整的输入数据；缺失输入会停止当日的计算；而在稍后与观测数据进行可选的比较时，会记录诊断结果而不会变更预报。

**修改前：** "At the start of each day, users define the inputs. The model calculates a forecast. An optional check compares it with observations. Missing inputs stop the calculation. Then the input values are updated."

**审查发现：** 开头暗示了每日的手动配置。每日数值出现在需要它们的计算之后。缺失输入的条件出现在预报之后，且诊断的后果未予说明。添加 `then` 并不能修正这些错误。

**修改后：** "Users first select the input variables supplied to the forecasting model. Their values are updated each day. If required inputs are missing, that day's calculation stops; otherwise, the model uses the updated values to calculate a forecast. Once observations become available, an optional comparison records the difference between the forecast and observations without changing the forecast."

**验收依据：** 修改后的路径为「配置 -> 每日数值 -> 预报」，其中缺失输入条件置于完成计算之前，且稍后可选的诊断与预报生成保持区隔。此变更保留了假定的来源事实；但并未确立真实实作即依循此流程。若既有文本已经清晰，且在未使用这些特定连接词的情况下表达了相同的关系，应予以保留。

<a id="function-preserving-concision"></a>
## 保留功能的精炼

将每个句子对应至一个或多个必要功能：主张、证据、解释、限定、综合或过渡桥梁。在删除科学实质内容之前，先移除或合并重复的功能。压缩重复的范例、平行的文献清单与重述的标准，同时保留精确的主张、其证据、推论界线与过渡桥梁。

仅将字数、句数以及与相邻段落的比较作为诊断依据。不要强加统一的目标值。若较简短的版本删除了必要的比较层级、文献引用、限制条件或转折，它就并非更好的版本。

对于已被接受、已提交或经指导教授编辑的基准版本，请进行能解决实际问题及其依赖关系的最小修订。保留运作良好的原始措辞；不要仅为了风格统一而改写相邻句子。若必须进行较大的结构性变更，在编辑前应先确认被更动的功能及其移放位置。批注标签仅标示为因应某项要求所作的修改，而非涵盖讨论同一主题的所有段落。

当批注仅选取该基准版本的局部时，请使用 [comment-scoped-revision.md](comment-scoped-revision.md) 来确立实际的当前锚点与完整批注讨论串、保留未选取的措辞，并为任何必要的延伸修改提供正当理由。为了连贯性而通读整段并不代表获准重写整段。较旧的范例仅用于引导论证或风格；请使用当前的事实与数据，而非范例本身的研究主张。

在精炼之后检查句子节奏。当极短的句子仅是为了表达 `Overall`、`However` 或 `The results are mixed` 时，应予以合并；当短句承载了必要的强调或完整的实质发现时，则予以保留。避免为了化解行文稠密而制造出一连串零碎短句。

<a id="natural-scholarly-prose"></a>
## 自然的学术行文

偏好使用具体的学术主词、直接的动词，以及目标领域读者能辨识的术语。每个概念保持单一术语，避免同义词轮替。透过让每个句子说明某个研究群组探讨了什么以及它如何推进该段落的论述，将文献清单转化为层层递进的论证。

为目标期刊广泛的学科读者写作，而不仅是针对狭窄主题的专家。当读者必须先解读非必要的概括性标签才能理解该主张时，应定义或替换该标签。例如，当灾害周期的各阶段在分析上并不重要时，应对防救灾相关任务进行具体描述，而非使用 `disaster management cycle`。

随时保持清晰的读者意识。为目标学术读者写作，切勿假定读者已熟悉本研究的特定概念、体制、模型逻辑、项目标签或数据处理选择。对于跨学科研究，应假定读者具备重叠的广泛研究知识，而非精通每个环节的专业知识。在读者初次需要处介绍必要的背景并解释术语的作用；仅拼写出缩写的全称并不能提供足够的理解。简明平实的语言旨在保留科学意涵与限定条件，而非使文字流于随意。

依据前置知识引导读者，而不仅仅是提供缩写定义。在说明群组差异之前先介绍相关背景或制度规则，并在使用群组差异的模型设定之前先介绍这些差异。在每个步骤提供足够的解释，使下一段陈述能够被理解；避免将实作细节引入背景中，或暗示某个缺乏所需特性的模型落实了现实世界的要求。

检查读者的认知负荷以及首次定义。即使正确展开了数个缩写，句子所比较的实体或关系仍可能变得模糊不清。保留必要的既定术语；在重复的简写迫使读者费力解读清单处，改用其具体角色或清晰的组别名称。不要将重新命名构念、轮替同义词或再次机械性展开每个缩写当作解决方法。

偏好使用明确的行动者、动作与比较参照对象。当语意不清时，请探问 “higher than what?”、“which difference?”、“whose loss?” 及 “what is the denominator?”。必要时将模糊的 `this difference` 或 `these limits` 替换为具体的结果或限制，而毋需重复整个定义。简明平实的学术语言所简化的是句法与信息呈现顺序，而非科学上的实质区分。

使主要行动者与动作保持清晰可见，而非将其埋没在冗长的名词堆叠或一连串的修饰限定中。在有助于读者理解关联时，先介绍已知信息再引入新信息。当过载句子的语意需要读者反复回读时，可调整顺序或拆分句子，但必须保留必要的专业术语、比较与不确定性。切勿强设字数上限，或用互不连贯的碎片句去替换一个稠密的句子。

例如，当句子涉及选择时，将 `flood adaptation decision-making process` 改为 `flood adaptation decisions` 可能更清晰；若涉及过程，改为 `how households choose adaptation actions` 可能更合适。应依据语意进行选择，而非依赖一成不变的禁用片语清单；切勿仅为了缩短名称而抹杀过程与结果之间的区别。

<a id="plain-scholarly-language-across-fields"></a>
### 跨领域的简明学术语言

目标是让来自其他领域且具备科学素养的读者，在不了解本研究内部简称的情况下，也能理解核心主张。这是一个可及性目标，并非保证所有潜在读者在缺乏背景知识的情况下都能跟上专业推导。保持学术精确性；简化通往该主张的论述路径，而不是用模糊或更强烈的主张来取代它。

1. 透过清晰可见的主词与动词陈述行动者或单位、测量概念及主要关联。在符合段落功能时，将研究发现置于从属细节之前，但切勿置于理解该发现所需的定义之前。报告差异时应明确指明比较基准；切勿让读者仅凭子图顺序或变数标签去猜测。
2. 在读者阅读需要之处提供最低限度的前置条件。保留必要的专业术语，并简要说明其在本研究中的意涵或作用；仅展开缩写全称未必有帮助。在独立段落中，若理解该主张需要用到新缩写或不熟悉的统计标签，应展开缩写并加以解释。例如，当所测量的数量是物种丰富度时，将其定义为观察到的物种数量。将定义写在易读的子句中，而非使用掩盖主词的巢状修饰语。避免使用较宽松的日常同义词取代已定义的构念，或添加教科书式的枝节讨论。应陈述缺失的背景脉络，而非捏造定义。
3. 保留决定该主张的分子、分母、单位、时间、母体、条件与不确定性。百分点差异不等同于相对百分比变化；标准化损失不等同于家户福祉。若简短的文字删除了这些区分或改变了比较基准，那就是失败的改写。
4. 既保留有支持的因果主张，也保留其局限性。切勿将观察到的关联转变为因果效应、将不显著的差异转变为相等，或将测得的中介结果转变为未测量的最终端点。反之，切勿机械性地将随机对照设计所确认的效应削弱为仅仅是关联。在不增加未经测试的机制或新证据的情况下解释结果的意涵；在有必要防止可能误读时，指明不能得出什么结论。
5. 修改完成后，在不查阅隐性起草历史的前提下进行「盲读」转述：研究了谁或什么、测量了什么、发现了什么比较或关系，以及该段落允许或不允许读者得出什么结论。找出支持每个答案的字词并检查修订句子的语法。当答案需要仰赖未经解释的术语、指涉对象、分母或逻辑跳跃时，请进行最小幅度的修订并重读现有的相邻句子。仅索取解决所请求主张所需之信息。切勿在描述性比较中默认存在干预，或仅为了提供局部临时修改而索取周围文本；无法取得相邻文本会限制对行文流畅度的主张。仅评估所请求的单元及受影响的依赖项。

请将此检查与句长或易读性评分分开处理。独立读者视角的评估可以发现剩余的理解问题，但模型流畅的转述并不能作为各领域真实读者皆能理解的证明。在测试中，除了核心要旨外，应对比确切的来源事实与修改内容；切勿奖励改变了科学意涵的较短措辞。

在进行明确的独立审查或屡次出现读者理解困难时，请使用 [independent-reader-review.md](independent-reader-review.md) 区分初次使用时的已知信息与稍后提供的定义。其盲读审查结果补充了这些局部的正文检查；它们并非要在每次编辑中都强加额外的代理人。

<a id="unpack-noun-chains-by-meaning"></a>
### 依语意拆解名词链

在起草与限定范围的正文审查期间，应标记在核心概念周围堆叠多个修饰词并迫使读者猜测其关系的名词片语。四到五个堆叠的名词是一个强烈的审查提示，而非放诸四海皆准的字数限制；较短的片语同样可能含混不清。在不将局部编辑扩大为全篇文件审查的前提下，将相同的检查套用至受影响的标题、图题与表格标签。

1. 辨识核心概念与预期的关系：是谁的、什么对什么做出反应、测量了什么、涵盖了什么，或是某项行动是为了什么。使用所提供的背景脉络或定义；若关系仍未确立，请提出具针对性的问题或提供明确带有条件的备选方案，而不是默不作声地自行选定一种。
2. 使用所有格、合适的介系词或包含主词与动词的子句，将这些关系明确表达出来。例如，在合乎预期语意时使用 `responses to a policy`、`coverage for contents` 或 `the wellness of households`。切勿机械性地插入 `of`、`for` 或 `to`；`wellness to ...` 并非通用的修复模式。
3. 保留已确立的专业术语、专有名词、既定构念及清晰的惯用复合词。切勿混用 wellness、well-being、welfare 与 willingness，或将意愿（willingness）的测量改变为观察到的行为。保留限定条件、比较组别、单位、时间与不确定性。添加连字号或轮替同义词并不能厘清隐蔽的关系。
4. 重读整个句子及其局部语境。确认读者毋需回读即可辨识该概念与关系，且该修订未增加因果关系、未改变测量指标，亦未制造出另一个稠密的片语。

将这项语意检验同样套用至简短的比较标签。在正文中，当读者无法辨识比较的是哪些组别或何种数量时，`group mean differences` 便是不完整的。应指明人员或资料来源、所测量的概念以及比较对象，然后以主词与动词表达该关系。若明确的统计术语或表格标题在该阅读边界处其组别与数量已经十分清晰，则应予以保留；作者在某篇论文中拒绝某个片语，并不代表全面禁用平均值比较。

不要将所有格视为充分的修复手段。`Human respondents' insurance willingness` 仍可能掩盖受访者究竟愿意做什么。当有相应关系支持时，偏好使用 `human respondents reported willingness to buy insurance` 或 `willingness to buy insurance among human respondents`。若该发现属于比较性质，应保留谁与谁进行比较；切勿在简化行动者时省略了比较对象。在采纳修订之前，应与来源对比方向、量级、统计显著性、等价性以及因果强度。将不显著的差异与平均值相等明确区分开来，并将陈述的意愿与实际的购买行为明确区分开来。

仅在陈述的语意获得确认时，才使用这些假设性的修复方案：

- `renter flood insurance purchase willingness` → `renters' willingness to buy flood insurance`，当该构念为意愿而非投保加入时。
- `human insurance policy responses` → `people's responses to insurance policies`，当政策是人们所回应的对象，而非收集其回应的单位时。
- `insured household wellness scores` → `wellness scores for insured households`，当 wellness 是本研究定义的构念，且纳保家户为评分母体时。

<a id="other-local-prose-checks"></a>
### 其他局部正文检查

依功能使用时态：已完成的流程与观察通常使用过去式，而图表描述与当前的解释则可使用现在式。在适当情况下使可比较的子句保持一致，但不要强求摘要（Abstract）、结果（Results）与结论（Conclusion）采用单一时态。即使是在经指导教授编辑的文本中，修复语法错误也应采用保留原意的最小修改；保留基准版本并不代表将错误认证为正确。

当学术惯用动词未增加任何实质意涵时，偏好使用字面本义的动词。若 `draw on data` 仅代表 `use data`，请写作 `use data`；仅在 `draw on` 能传达使用 `use` 就会流失的更广泛学术或证据依赖关系时，才保留该用词。将相同的检验套用至其他听起来优雅的片语，而非机械性地轮替它们。

在阅读时兼顾语法与节奏感。标记重复的句型、过度的平行列表、冗长的名词堆叠、模糊的行为主体（例如在学术领域或证据来源更明确时仍使用 `researchers` 或 `studies`），以及重复的指示代名词句首（如 `This`、`These` 或 `Such`）。仅在修改能改善语意、流畅度或证据连结时才进行修订。

<a id="sentence-pattern-variety-without-changing-logic"></a>
### 不改变逻辑的句型多样性

将稳定的论证顺序与重复的语法支架区分开来。一段文字可能正确地依序呈现「发现 → 证据 → 解释」，却不必要地重复相同的句型。审视句首族群，而非仅检查完全相同的字串：即使动词不同，`We first ... / We then ... / We next ...`、`These results show ... / These findings indicate ...` 或重复的 `By ... , we ...` 子句听起来仍可能显得单调重复。

进行段落层级的工作时，请检视整个段落及其可参考的相邻段落。进行小节或章节层级的工作时，还应依序阅读各段的开头与结尾，以检查是否存在重复的句式支架。单一句子的语法修正并不代表获准为了多样性而重写相邻段落。确定性扫描会将段落内三个相邻的流程性 `We` 框架标记为审查提示；它并不会剖析所有句子结构、设立通用配额，或认证更广泛的文体多样性。

保留实际的顺序、依赖关系、专业术语、行动者与比较基准。在有助益的情况下，可合并相依步骤、将相关数据或结果作为主词，或删除未增加任何信息的顺序词。切勿仅是将 `then` 轮替为 `next`、将每个句子都改成被动语态，或为了避开重复而替换已定义的专业术语。当刻意的平行对称有助于读者理解对等比较与流程顺序时，应予以保留；请记录保留的原因，而非将诊断提示直接当成自动判定错误。

例如，以下假设性措辞可以在不改变流程的情况下进行修复：

- 修改前：`We first fit the income distributions. We then sample incomes from these distributions. We next calculate losses relative to income.`
- 最小修订：`We fit the income distributions and sample incomes from them. The sampled incomes are then used to calculate losses relative to income.`

谨慎使用句首的 `Beyond X,` 与 `Taken together,`，切勿将其作为默认的过渡桥梁或总结。偏好直接点名新增的证据、实际边界或综合发现。当 `Beyond X,` 确立了实质的延伸时予以保留，当句子确实综合了不同证据时保留 `Taken together,`。切勿机械性地以另一种套话连接词来替换它们。如 `floodwater extended beyond the boundary` 这样的字面措辞并不属于套话转折。这两种句首形式都会接受语境诊断；项目特定的较强偏好仍保留于正文剖析设定档（prose profile）中。

起草完成后，大声朗读该确切段落，或模拟研究人员在自然情境下会如何表达。检验标准不在于文字听起来是否像口语对话，而在于句子能否以正常步调朗读、其主词与动作是否保持清晰，以及听者能否依照信息呈现的顺序理解。若段落听起来像生硬拼凑、需要反复回读，或包含研究人员不太可能说出口的措辞，请予以重写。

<a id="gap-statements-and-comparative-framing"></a>
## 研究缺口陈述与比较架构

将主要任务动词视为科学主张的一部分。唯有当动词与研究实际的推论目的及分析相符时，才使用如 `compare`、`characterize`、`estimate`、`predict`、`validate`、`reproduce`、`replicate` 或 `evaluate` 等动词。切勿仅因为较强势的动词听起来更具重要性，就将描述性比较转变为能力、验证、等价或通过／失败的主张。当研究探讨两种证据来源有何差异或如何对齐时，应直接陈述比较内容，而非暗示某个来源被预期要重现另一个来源。

将研究缺口撰写为具体缺失的知识、证据、比较、机制、研究母体、尺度或分析层次。除非句子或相邻语境确切指明了什么尚未被检验，否则应将如 `remains unclear`、`is not well understood` 或 `little is known` 等片语视为不完整。在有文献支持的情况下，偏好具体陈述文献现况（例如 `has not been examined`、`has rarely been compared` 或 `remains largely unexamined`），同时避免提出检索基础无法支持的绝对新颖性主张。

避免将研究对象、结果、比较来源、母体、尺度与分析层次全塞进一个冗长的名词堆叠中。将核心比较或未知事物置于「主词－动词」核心中，必要时再以独立的片语或句子补充整体、子群、时间、空间或方法学的处理范围。读者应在读完整个句子之前，就能辨识出究竟缺少了什么。

在论文所能证实的层次上陈述该缺口为何重要：解释、理论、方法选择、政策推论、计划设计、决策支援、可转移性，或其他实质影响。其重要性可出现在同一句或下一句中；不要强求每个缺口句都必须包含它。当稿件可以直接指明仰赖该缺失证据的具体决策或推论时，请避免使用泛泛的重要性宣称。

当相近的前人先例与本研究高度重叠时，应利用它来界定研究边界，而非将其视为对新颖性的威胁。陈述该研究实际比较或确立了什么，进而指出仍待探索的不同分析层次、结果、结构、母体或推论。若先前研究已涵盖了某类比较的较狭窄版本，切勿宣称 `no study` 完成了一大类比较。

<a id="claimcitation-alignment"></a>
## 主张与引用文献一致性

将每个句子拆解为可独立查核的主张。针对每项主张，指明支持它的引用文献或稿件证据。句尾的一组文献引用必须支持其看似涵盖的每个实质子句；否则应拆分句子、缩小主张，或调整文献引用的位置。

对于合并引用的文献，请核实每个被引来源皆符合所指明的领域、方法、结果或限制。切勿仅因为某篇引用文献曾出现在先前的草稿中就予以保留。当主张被精简压缩时，应重新检查留存的引用文献群是否仍能支持新的综合论述。当从某段文字中删除某项引用时，在更改参考文献清单之前，请确认该文献是否仍在其他地方被引用。

当主张仰赖文献来源的具体细节时，切勿单凭标题或记忆来认证主张与引用文献的支持关系。请在符合该主张所需的深度下阅读原始文献、摘要或权威记录。将经核实的支持与看似合理的主题相关性明确区分开来。

当被引用的研究报告的关系方向与当前样本或研究区域所校准或估计的相应关系不同时，切勿直接附上引用文献而留下未加解释的矛盾。在引用文献之前或同时说明处理范围的差异：此处报告的关系反映了当前的样本或地点，而若被引证据支持该项限定，则该关系在其他母体、地点或环境中可能有所不同。保持此免责说明简短且有证据支持。切勿将校准出的关系改写为模型假设、暗示相反证据会自动使本研究结果无效，或凭空捏造文献来源未支持的语境变异。若无法从现有证据中化解此差异，请陈述尚未解决的对比，并将其解释保留给讨论（Discussion）部分。

<a id="observable-stock-or-ai-like-prose"></a>
## 明显的套话或 AI 风格行文

切勿从写作风格推断作者是否为 AI。仅报告可观察到的特征：空洞的后设话语、套话转折、泛泛的综合论述、重复的指示代词句首、过度的预告与总结语言、对称但内容贫乏的分类清单、重复的节奏、模糊的主词，或缺乏支持的共识主张。

评估组合搭配与局部密度，而非单纯禁用孤立的片语。常见片语偶尔出现一次可能很自然，但若连续出现几个就会显得公式化。仅在能更精确陈述实际关系或证据时，才替换该措辞。

将针对句首 `Beyond X,` 与 `draw on` 等形式的诊断视为读者可及性检视的提示，而非措辞有误的证明。检查读者是否毋需先解读转折范本、领域标签或间接动词，就能陈述该句子的具体主张。

<a id="dash-and-hyphen-style"></a>
## 破折号与连字号格式

在编辑前区分三种情况：

1. 作为标点符号使用的句法长破折号（em dash）或短破折号（en dash）；
2. 复合修饰词、专业术语、范围或名称中的词汇连字号（hyphen）；以及
3. 悬空复合词，例如 `subgroup- and topic-specific`。

不要强加全面禁令。当连字号能避免歧义、依循既定术语或专有名词，或符合发表管道的语言惯例时，应保留复合词。当该领域通常将其视为名词片语且不会产生歧义时，偏好使用开放式复合词（不加连字号）。当自然的片语更为清晰时，应改写悬空复合词以及多个非技术性连字修饰词聚集的情况。

不要仅因为既定的开放式复合词置于另一个名词之前，就添加连字号。判定该复合词的语法角色并核实其惯用形式；例如，在 `disaster management phases` 中保留 `disaster management`，而非自动写成 `disaster-management phases`。当项目或发表管道确立了开放形式时，请将其注册在 `style_profile.preferred_open_compounds` 中，以便精确候选版本审查能回报带有连字号的变体。

在句子与段落层级检视破折号的密度。即使语法正确，若多个破折号密集出现，仍可能干扰阅读。检查破折号是否掩盖了一个本应调整顺序或进行拆分的过载句子。

<a id="exact-candidate-procedure"></a>
## 精确候选版本程序

在最后一次字词更动后：

1. 冻结该精确候选版本，并在支援时记录其杂凑值；
2. 在所要求的深度与变更影响范围下，针对该确切文本重新执行上述适用的审查；
3. 将前一段与后一段连同该版本一起阅读；
4. 在语境中检查每项确定性诊断，并记录为何保留任何被标记的形式；
5. 将新增、删除及受主张影响的引用文献与参考文献清单进行核对；针对实质性审查检查留存的支持证据，而毋需在仅涉及语法的编辑中重新认证未更动的来源；
6. 针对该精确候选版本执行目标读者视角检查与大声朗读检查；以及
7. 若事后更动了任何文字、引用或标点符号，则该审查失效。

若仅有较早的候选版本通过检查，切勿称该段文字为最终定稿、经润色、自然、精炼或经引用查核。
