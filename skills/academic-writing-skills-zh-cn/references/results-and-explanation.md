<a id="scope-and-evidence-order"></a>
## 处理范围与证据排序

在规划、起草或实质性审查各项发现时请使用本指引，包括在其他标题下的综合发现、命题及基准评估。保留运作良好的已提交或经指导教授编辑之文本；修复缺失的功能，而非全盘重写该节。

一旦读者知晓所比较的事物，即可围绕着「**发现 → 必要证据 → 意涵 → 实质性回答**」来组织结果单元。如下文所述，首先补足任何缺失的图表导引说明。这些是信息功能，而非四个强制的句子。陈述发现了什么、指明比较对象、报告足以做出评判的证据，并说明该结果就研究问题而言确立了什么。将可重现的流程置于方法（Methods）中；仅在理解某项发现需要设计细节时简要回顾。

在安排支持性数值之前，先选定主要模式或比较。不要机械性地列举变数、组别或子图：读者应当明了这些数值论证了什么，而非必须从数值清单中去推导发现。当变数、子图或时间顺序有助于推进清晰的分析论点时，采用此等顺序是合适的。研究发现可能是异质的、具不确定性的，或是未显示明显变化；「模式优先」的写作方式并不代表获准提出更强烈的主张或捏造机制。

在段落或小节完成其分析论点之处给出 “so what”。它可以指明路径对比、取舍权衡、边界、获得支持的关系或负面发现。切勿仅以统计数据、“These results answer SQ1,” 或泛泛的重要性宣告作为结尾。暂时移除研究问题标签与导言式的后设话语：该回答本身仍必须易于理解。带编号的 SQ/RQ 标签是可选的导航工具，而非证据。

以连贯的结果单元建立该项解释，而非将所有意涵推迟到最后包含一切的总结句。数个数值可以支持同一项发现：将它们保留在一起，说明该项比较确立了什么，然后让下一个单元对其进行深化、对比或限定。例如，在转向离散度之前先确立分数水准所代表的意涵，并在得出群体层级的结论之前区分个别关系与整体模型比较。所需的过渡桥梁是分析上的关联，而非另一个连接词。不要在每个数字后面都插入解释、不要在每个段落都重复研究问题，也不要拆分运作良好的多数值发现。

对于跨多个分析层次展开的比较，应指明当前层次贡献了什么，而不仅是它出现在序列中的何处。在起草前，先说明比较了哪个层面、其证据能确立什么，以及后续的比较将增加什么或必须兼顾什么。起草后，在移除研究问题标签与套话框架的情况下，直接从正文中梳理出这些关系。在条列结果后加上 "this is the first level" 或 "this answers RQ2" 并不能提供所缺失的关联。当数个数值支持同一项发现时，应将其置于同一处；不要规定每个段落都必须有目的句或论述路径图。

区分当前层次的发现与其对后续解释的相关性。例如，不同的测量输入可为分数比较提供脉络背景，但这并不代表它能解释每项分数差异，也不代表它禁止了后续的关系比较。仅陈述所提供之设计所能支持的结果。将证据及其解释放在一起；将技术性表格指引置于有助于阅读而非打断该单元之处。当此特定执行缺口再次出现时，请使用 [evidence-context case 11](evidence-context-cases.md#11-comparison-contribution-is-not-a-sequence-label)；运作良好的正文则应维持不变。

<a id="visuals-and-substantive-answers"></a>
## 视觉图表与实质性回答

每张图表偏好设定一个主要问题或分析目的。这并非强制的「一图一问」比例：相关的子图可以支持一项渐进累积的比较，多张视觉图表也可以共同回答一个问题。当不同子图群组的相异目的模糊了论点时，应将其拆分；切勿仅为了符合比例而增加图表数量。

在呈现图表之前，若语境需要，应先提供研究问题或比较。在提供必要证据之后，于单元的自然边界处陈述答案。不要在每个子图周围都重复完整的预览与综合论述。将数值追溯至实际的输出与图表展示，核对基准线、组别、时间、单位、分母、聚合方式、摘要统计量、不确定性与四舍五入。显示的四舍五入端点毋需完全精确重现由未四舍五入数值计算出的百分比；应核实底层计算，并在四舍五入具有实质影响时予以说明，而非借由更改数值来强求一致。

<a id="first-and-repeated-display-encounters"></a>
### 图表的首次出现与再次出现

在首次遇到不熟悉的图表展示或比较时，在报告数值前，应先简要告知读者它展示了什么证据、比较了哪些实体或条件，以及应注意观察什么。对于分布图，应区分分数或测量值、母体，以及比较关注的是位置、离散度还是形状。仅在该项发现需要时才解释不明显的编码方式；将完整的图例与绘图流程保留于图题和方法（Methods）中。若相邻正文已提供了该导引说明，切勿重复添加。

接着陈述观察到的模式，以相关数值加以支持，并在段落或小节的自然收尾处解释其有依据的意涵。单单一句「Figure X presents the results」并不能引导读者，但当主词与目的已很明确时，以图表开头的句型或动词 "presents" 本身并非本质上有错。切勿以纯粹的后设话语取代以研究发现为导向的实用开头。在解释中，指明是谁的数值在何种层次上变异；如 "less variation in the summaries" 这样的片语可能会掩盖人与人之间、地点之间或重复执行之间的变异。精简行文必须保留该项区分。

对于后续使用相同既定阅读逻辑的图表展示，请承接该脉络，仅介绍新的母体、条件、比较或发现。不要针对每张图表都重复绘图教学、图例或 "we first / we then present" 框架。当数量、分母、母体、编码方式或不确定性发生变化时，或当该单元必须独立成篇时，请重新引入其意涵。相同的绘图类型并不代表估计标的（estimand）相同。请将相同的决策准则套用至表格、地图、质性图表与证据综合分析，而非假定每个结果（Results）章节都包含分布图。

针对图题、注释、视觉尺寸及同步性检查，请使用 [figures-tables-and-supplements.md](figures-tables-and-supplements.md)。

<a id="mechanisms-and-logical-flow"></a>
## 机制与逻辑流向

<a id="resultexplanation-continuity"></a>
### 结果与解释的连贯性

将结果及其解释视为连贯的正文阅读，而非各自单独润色的句子。在其交界处，指明该解释所诠释的具体观察比较为何，以及该诠释增加了什么。一连串正确的短句若在未提供该关联的情况下改变了主词、比较、分母或分析层次，读起来仍可能像是互不连贯的笔记。

以最小的修改修复该关系：指明被解释的结果、将必要的比较置于其旁、重排前提顺序，或在子句的对比、条件或限定本属于一体时将其合并。不要合并每个短句、不要强加最小句长限制，也不要添加套话连接词。保留清晰简短的散文与专业区分；若该关系需要目前无法取得的证据，请说明该限制，而非为了使段落流畅而凭空捏造原因。

例如，若仅给定各组平均值相似且 A 组的人与人之间的变异较小，`The means were similar. A was concentrated. The groups agreed.` 并未能严谨稳妥地传达该项比较。最小修订是 `The groups had similar mean scores, but responses varied less among people in group A.` 这将所提供的发现连结起来，而未宣称对等一致或等价。这是一个假设性的说明，并非要把所有结果合并成单一句子的规则。

区分模型或程序规则、观察到的输出、由分解法或其他适当分析支持的解释，以及貌似合理但未经检验的诠释。单凭规则并不能确立为何会出现总体模式。支持现实世界机制的文献引用，并不能证明该机制在当前数据集或模拟中有所运作。

透过明确的关系将解释与所报告的模式连结起来。“A therefore B” 要求该连结具备证据支持，而不仅是看似合理的时间或逻辑顺序。若解释尚未经检验，在文体将结果（Results）与讨论（Discussion）分开的情况下，应对其加以限定，并将延伸诠释置于讨论部分。在结果部分进行简明的限定说明可以防止误读，同时不至于演变成推测性的因果叙事。

不要从群体平均值推论个体变化、不要从多个同时发生的变化中单独分离出单一原因，也不要将情境模拟机制转变为实证验证。指明确实展示出的贡献，以及提出更强烈主张仍需要的诊断分析。不要仅仅因为正文审查揭示了该缺口就直接去执行该诊断。

<a id="hidden-comparison-checks"></a>
## 隐含比较检查

在章节收尾处，请使用 [lifecycle-and-routing.md](lifecycle-and-routing.md) 选取适用的问题。不要对每种研究设计都硬套每项数值检查。

| 内容触发条件 | 采纳该诠释前应检查的事项 |
|---|---|
| 变动的群体平均值或轨迹 | 成员异动、迁移、损耗、重新分类或加权是否可能改变其组成成分？在证据允许的情况下，将单位内部变化与组成成分变化区分开来。 |
| 比率、缩减或标准化 | 是否指明了参考组／参考情境／参考时间？分子、分母、加权、聚合顺序以及初始／当前母体是否清楚？相等的百分比单位可能掩盖不同的实质意涵。 |
| 排序曲线或分位数差异 | 数值是否在相同机率下、或针对相同观察／事件进行比较？切勿将各自独立排序的曲线差异称为事件配对的给付或处理效应。 |
| 重复试验、误差线或区间 | 代表了何种不确定性：随机试验、测量、抽样、参数还是序列？切勿将有条件的模拟变异性转换为涵盖所有不确定性。 |
| 空间类别或颜色改变 | 颜色代表的是等级、变化还是联合类别？类别边界可能掩盖微小但非零的变化；颜色改变本身并不能作为新机制或推翻主要结论的证据。 |
| 看似相似的结果 | 相似性仅是描述性的，还是依照明确标准检验过等价性／一致性？切勿捏造正式检定。 |
| 共享量表上不同构念的分数 | 所陈述的基准是否支持对各个分数的诠释？共通的范围或中点并不能确立哪个构念更重要、更强烈或更有影响力。在计分意涵明确时，描述性数值可予保留。 |
| 组件检定后接着提出群体或模型主张 | 证据是否检验了确切的对比与层次？各组内部各自的显著性不能确立组间差异；数个不显著的组件不能确立整体模型的等价性。保留核心的负面发现，切勿将其提升为等价。 |
| 统计显著性后接着提出重要性主张 | 实质重要性是否获得效应量、不确定性、相关基准及研究脉络的支持？单凭微小的 p 值完全无法提供上述任何支持。 |
| 质性主题或综合计数 | 计数属于范例说明、编码出现次数，还是盛行率估计？保留反例与证据边界；切勿将出现频率提升为母体普遍性。 |
| 定理或架构应用 | 结论获得哪项前提或要求的支持？范例展示并不能确立所有宣称的边界条件或广泛实用性。 |

例如，在变动的邻里样本中，认知平均值的下降可能反映了个人数值的降低、成员组成的改变，或两者皆有。在缺乏追踪个体单位的证据时，应报告总体下降，而将其具体分解留待未决。这是一个假设性的诊断说明，并非针对任何论文规定的解释。

<a id="reader-test"></a>
## 读者检验

在视觉图表呈现为预期尺寸的情况下阅读该结果单元。读者是否能解释比较了什么、改变了什么、证据如何支持该解释，以及该发现为何对研究问题至关重要？若无法，请修复该特定缺失的环节。依序阅读开头句与结尾句以检验渐进累积的逻辑，而非检验是否符合套话句型。回报无法取得的证据，而非认证未看过的产出。
