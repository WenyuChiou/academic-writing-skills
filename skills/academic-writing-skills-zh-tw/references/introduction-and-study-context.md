## 處理範圍與推展順序

即便稿件採用其他標題，亦請運用本指南來落實「引言」或「研究背景」章節的讀者功能。請遵循作者宣告的推展順序。對於實證文章，一個有用的起始順序是：引言 → 研究背景 → 方法 → 結果 → 討論 → 結論 → 從穩定文本重塑摘要。這並非適用於所有文類的必備結構。當後續證據改變了研究能回答的問題時，請重新檢視早期的研究定位。

在起草之前，請確認研究目的、設計、目標受眾、可用來源以及相關的研究事實。缺失的選取理由、來源支持或處理範圍細節，乃是尚待解決的未知數，切勿藉機自行捏造。請套用 [universal-integrity.md](universal-integrity.md) 與 [prose-and-citation-editing.md](prose-and-citation-editing.md) 中通用的段落與讀者指引規則。

請運用以下功能規劃所要求的單元。當不同的邏輯關聯更有助於讀者理解時，各功能得予合併、分散於數個段落或重新排序。切勿將表格化為死板的四段式範本、強制要求編號的研究問題，或將局部編輯擴大為全篇論文審閱。

<a id="introduction"></a>
## 引言

「引言」確立了為何需要本研究，以及其研究目的是如何從既有知識中推展而來。

| 讀者功能 | 起草決策 | 應避免事項 |
|---|---|---|
| 確立問題及其重要性 | 從能直接引導至實際問題的高度展開；指明處於關鍵的核心理解或決策。 | 寬泛宏大的開頭，其與本研究的關聯直到很晚才顯現。 |
| 確立已知成果 | 依推展論點的關聯組織各項研究；利用密切的先例確立哪些問題已被探討。 | 個別論文的清單盤點，或藉由略去重疊工作來製造新穎性。 |
| 指明研究缺口及其重要性 | 指名未解決的知識、比較、母體、尺度或分析層級，及其具正當理由的後果。 | 未加說明的 “remains unclear,”、缺乏支持的 “no study,”，或泛泛的重要性主張。 |
| 陳述研究目的與途徑 | 從缺口引出目標或研究問題；提供最低限度的宏觀途徑以及受證據約束的預期貢獻。 | 與缺口無關的問題、實作細節，或超出研究設計所能支撐的過大貢獻。 |

在利用概念或制度背景來說明群體差異或提出研究問題之前，請先介紹理解問題所需的相關背景。切勿假設讀者已經知曉特定區分為何重要。詳細的研究地點描述與可重現的程序，應保留在具備該功能的專門章節中。

當缺口主張描述了當前的研究現況時，請查核文獻檢索與密切先例是否足夠即時，得以支持該主張。較舊的文獻來源可確立基礎性問題，但無法證明該問題至今仍未被檢視。必要時請檢索或檢視較新且名稱不同的文獻；否則應限縮該主張並陳述核實界限。切勿強設文獻年份截止點，亦不可僅因基礎文獻年代較久就予以替換。

當提出數個研究問題時，請使它們之間的關聯清晰易懂：它們可能是獨立、循序或層級關係。檢查每個問題是否增添了不同的答案並具備證據途徑；指明何時需要某個答案才能回答另一個問題。切勿強求獨立性、將單一比較拆成冗餘的問題，或僅憑問題順序便推斷因果識別。編號與引言路徑導覽圖仍屬作者或發表管道的選擇。

在章節處理範圍層級，檢驗讀者能否辨識出問題、既有知識、缺失環節、該缺口的後果以及本研究的回應。請將段落的開頭與結尾對照閱讀：它們應推展論點，而非反覆宣稱重要性或新穎性。段落層級的任務查核的是其對該推展鏈的貢獻與可用的相鄰文本，而非整篇「引言」中的每一項功能。

<a id="study-area-context-and-evidence-setting"></a>
## 研究區域、情境與證據設定

本節確立了詮釋研究設計所需的情境設定、採用該設定的理由，以及證據的實際處理範圍。本節並非通用的地理或人口百科全書。在非地理研究中，相應的情境設定可能為母體、機構、資料集、實驗環境或案例。

| 讀者功能 | 起草決策 | 應避免事項 |
|---|---|---|
| 描述相關情境 | 挑選有助於讀者理解研究問題或研究設計的地理、社會、體制或抽樣背景。 | 在後續研究中毫無作用的背景事實。 |
| 解釋選取理由 | 陳述採用該地點、母體、資料集或案例的實際理由，相關時亦包含實際的資料可用性。 | 在缺乏支持證據的情況下，推斷所選案例具有理想性、典型性或代表性。 |
| 界定證據界限 | 在詮釋所需的層級上，指明實際的空間、時間與母體處理範圍。 | 將整個區域等同於分析領域，或將目標母體等同於實際取得的樣本。 |
| 為「方法」提供前置條件 | 解釋理解後續設定所需的背景概念或體制區分。 | 過早引入參數或演算法，或僅因在此處描述了現實規則，便暗示該規則已被本研究所實作。 |

請區分宏觀情境、分析領域或抽樣底冊，以及實際觀察或生成的單元。對於調查研究，相關時應區分目標母體、合格母體或抽樣底冊，以及實際取得的樣本。對於模擬研究，應區分觀察到的情境事實與合成指派。選取理由並不能確立代表性或廣泛的推論普及性。

相關的體制背景可能超出研究實際實作的範疇。解釋其作用時，切勿暗示所有此類規則皆已建立模型或已獲強制執行；視需要於「方法」與「研究限制」中說明實際的再現方式與實質省略。在此階段，背景解釋的是為何某項區分至關重要；「方法」解釋的則是本研究如何將其操作化。

在章節處理範圍層級，檢驗讀者是否知曉相關情境、為何選取該情境、實際研究了什麼，以及是否有足夠背景理解「方法」。維持經審閱之地圖、圖表說明、表格與描述的一致性。切勿僅為了結束該章節而添加結果風格的 “so what” 或 RQ 標籤。

<a id="first-three-section-handoffs"></a>
## 前三節的交接承接

將「引言」、「研究背景」與「方法」視為讀者的推展鏈：**為何提出此問題 → 採用何種情境與證據處理範圍 → 研究如何回答該問題**。請檢驗各節之間的交接承接，而非機械式遵從三個標題或固定的段落順序。

| 交接環節 | 查核其關聯性 |
|---|---|
| 引言 → 研究背景 | 實際案例或母體是否符合研究問題，且其選取理由是否在未捏造代表性的情況下予以陳述？ |
| 研究背景 → 方法 | 進行該程序所需的概念是否已獲介紹，且是否清楚釐清哪些情境事實是測得的、合成指派的，或僅作為背景？ |
| 方法 → 陳述之問題 | 從規劃的產出反推，該程序能否在陳述的處理範圍與推論層級上，產生研究問題所需的那類證據？ |

透過相關交接環節，追蹤實體或單元、概念或結果變數、時空處理範圍以及允許的推論。存在差異可能是合理的：例如，外部調查資料可為案例模型提供資訊，而無須直接作為被模擬家戶的觀察資料。請陳述其實際作用與任何轉移假設，切勿強求各來源具備完全相同的涵蓋範圍，亦不可默認它們可以互換。

相同概念在這些章節中扮演不同角色。「引言」解釋為何重要；「研究背景」確立其在地相關性與條件；「方法」陳述其實際再現方式、設定參數與實質省略。請簡短回溯參照，而非重複完整解釋。對於操作性來源出處，請使用 [methods-and-assumptions.md](methods-and-assumptions.md)。

<a id="hidden-mismatch-checks"></a>
## 隱蔽不符之檢查

當主張或研究設計使這些問題具備相關性時，請運用它們。它們揭示了可辨識的隱蔽不符形式；但它們並非窮盡未知之未知的偵測器，亦非重寫運作正常章節的理由。

| 問題隱匿之處 | 診斷問題與可能的修復方案 |
|---|---|
| 以新標籤描述的缺口 | 是否已有密切先例在其他術語下實質探討了相同的任務？在斷言新穎性之前，請先比較實際的研究問題、結果變數、尺度與證據。 |
| 宏大的目的與較狹隘的測量結果 | 研究問題關乎福祉、因果機制或群體行為，而規劃的證據卻涉及模型化的資產損失或描述性關聯？請陳述有依據支持的任務；切勿重命名產出以暗示測量了更廣泛的構念。 |
| 案例選取與資料可用性 | 選取方式或缺失的涵蓋範圍是否限制了所能獲知的結論？請回報實際的選取過程與相關界限；切勿憑空捏造偏差、宣稱無效，或僅憑涵蓋範圍便主張代表性。 |
| 地圖或情境百分比 | 基於面積的數量是否被誤用作基於家戶或人口的數量？請指明任何映射或指派假設，而非默默將這些單元劃上等號。 |
| 體制背景轉變為模型主張 | 規則的條件是否得以保留，且讀者是否知曉本研究究竟是再現了資格、法規遵循、強制執行，還是皆無？若簡化再現的角色與界限明確，該再現即可具備正當性。 |

當出現不一致時，應找出確切缺失的環節、解決該問題所需的來源，以及獲授權的最小幅度修復。若解決問題需要新資料、變更研究問題或更換不同模型，應標記該項決定，而非藉由文字敘述暗中補足。

<a id="placement-and-revision-checks"></a>
## 配置與修訂檢核

應依內容的功能配置內容，而非僅憑其主題：

- 理解研究問題所必需的背景 → Introduction（緒論）；
- 個案特定脈絡與實際證據的處理範圍 → 研究脈絡或對應的情境章節；
- 設定指派、參數、資料轉換、抽樣程序與演算法 → Methods（方法）或該文類的程序章節。

同一概念可能因不同目的出現在多個章節中；無須每次都重複其完整說明。若特定文類或發表園地將這些功能整合於不同標題下，應予尊重。

對於新草稿，在決定段落界線前，應先規劃各項功能與證據。對於已獲接受、已投稿或經指導教授編修的草稿，應找出缺失或錯置的功能，並進行最小且有依據的修復。切勿僅為了符合本指南而重構運作良好的段落。若內容必須搬移，請指明其目標位置，並檢核受影響的轉折與參照。

使用 [lifecycle-and-routing.md](lifecycle-and-routing.md) 進行處理範圍與變更影響檢核。研究缺口或研究問題的變更可能會影響證據鏈與摘要；局部的語法修復並不代表有權重寫這些內容。
