<a id="diagnostic-prose-patterns"></a>
# 散文診斷模式

以下項目應予以刪除、替換、量化或說明其合理理由。使用中的專案寫作契約、受保護的術語以及專案特定的 `style_profile.discouraged_phrases` 具有優先權。

本檔案涵蓋跨領域通用的陳腔濫調詞彙與散文模式。將每個相符項視為需要脈絡判斷的診斷發現，而非 AI 撰寫的證明或自動刪除規則。針對跨領域外來行話、不必要的複合標籤、句子結構與文獻引用安全的修訂，亦請套用 [prose-and-citation-editing.md](prose-and-citation-editing.md)。

<a id="1-single-words"></a>
## 1. 單字

<a id="verbs"></a>
### 動詞

| Avoid | Prefer |
|---|---|
| delve | examine, investigate |
| utilize | use |
| leverage | use, apply, draw on |
| harness | use |
| navigate | address, handle |
| foster | encourage, produce |
| showcase | show, present |
| underscore | show, emphasize sparingly |
| bolster | support, strengthen |
| garner | receive, gather |
| embark | begin |
| unpack | explain, examine |
| endeavor | aim, work |
| elucidate | show, explain |
| substantiate | support |
| facilitate | enable, allow, or rewrite |
| exemplify | show, illustrate |
| conflates | confuses, treats as the same |
| entails | carries, involves |
| attained | reached, results from |
| reproduces (an effect or inequity) | repeats, extends |
| misreads (a figure or number) | mistakes ... for |
| collapses (X to Y) | reduces (X to Y) |

<a id="adjectives"></a>
### 形容詞

刪除或量化：crucial, pivotal, intricate, meticulous, vibrant, robust,
nuanced, multifaceted, comprehensive, paramount, imperative, indispensable,
noteworthy, novel, innovative, holistic, seamless, substantial, substantive,
major, dramatic。其中有幾個詞在某些學科中屬於領域原生用語（請參閱下方的領域原生豁免）。

<a id="field-native-exemptions"></a>
### 領域原生豁免

此豁免同時規範上方的動詞表與形容詞清單。其中某些詞彙在特定學科中屬於常規語域，並出現在該領域已發表論文的很大比例中。例如在水資源與水文學中，動詞 "facilitate" 以及形容詞 "robust"（a robust optimization algorithm, a statistically robust test）、"comprehensive" 和 "substantial" 皆被常態且正當地使用。在此類領域中，應將這些視為密度檢查（僅在單一章節中某詞出現多次時才標記），而非按次計算的規則。請在進行中的專案寫作契約或風格設定檔中記錄豁免清單。檢視 §2 與 §2a 中的多詞陳腔濫調片語之功能與局部密度。

"novel" 與 "first" 在本文章節（Introduction、Methods、Discussion、Conclusion）中，只有在表示真正的方法或模型首創，且在同一子句或下一子句中以知識範圍限定語（"to the best of our knowledge, this is the first study that ..."）加以限定時，才可謹慎使用。未加限定的 "novel"/"first" 仍然屬於過度主張。Results 章節特意排除在該清單之外：在 Results 段落中的 "novel"/"first" 主張幾乎總是屬於貢獻主張而非研究發現，因此請將其移至 Introduction 或 Discussion。在摘要中，請採用更嚴格但能兼顧發表管道特性的預設做法：除非該主張在可用篇幅內屬必要、界定明確且有充分支持，否則應省略新穎性或首創性主張。

限定條件是必要的，但非充分條件："to the best of our knowledge" 降低了語氣，但並不能確立事實。請將每項帶有限定條件的新穎性或首創性主張送至主張–證據帳則，並對照相關文獻進行驗證；切勿僅憑限定字串就予以放行。只要有任何先前研究存在，即使前面加了限定詞，該主張仍屬不實。

"Significant" 可用於統計顯著性。不可用作一般的加強詞。

避免新聞報導語域（新聞文章措辭）：harder-hit, hidden cost, staggering, eye-watering, a stark reminder。改為平實陳述數量或機制（例如，*harder-hit* 改為 *bears the larger loss*）。

<a id="adverbs"></a>
### 副詞

通常刪除：undeniably, remarkably, notably, crucially, importantly,
ultimately, meticulously, markedly, substantially, considerably。

當用作贅詞時亦應刪除（但帶有技術性內容時不在此限，例如 *statistically significantly* 或 *spatially explicitly*）：essentially,
fundamentally, inherently, particularly, specifically, effectively, largely,
broadly, generally, relatively（未附比較基準時）, arguably。

<a id="redundant-qualifiers"></a>
### 冗餘修飾語

刪除修飾語——名詞本身已具備該含義：

| Redundant | Use |
|---|---|
| completely unique | unique |
| absolutely essential | essential |
| totally novel | novel (and quantify why) |
| fully comprehensive | comprehensive (and quantify) |
| extremely critical | critical (and justify) |
| deeply concerning | concerning (and state the consequence) |
| highly significant | significant (with statistical evidence) |
| very important | (delete; if it matters, the sentence will show why) |

<a id="metaphorical-nouns"></a>
### 隱喻性名詞

避免使用：tapestry, landscape 作為隱喻, beacon, realm, interplay, synergy,
testament, paradigm, cornerstone。

## 2. 需檢視的陳腔濫調片語

- "It is important to note that..."
- "It is worth noting that..."
- "In recent years..."
- "In today's world..."
- "plays a crucial role"
- "provides a comprehensive framework"
- "as mentioned above"
- "as established earlier"
- "beyond this"
- "in this regard"
- "with respect to this"
- "sheds light on"
- "a testament to"
- "the interplay between"
- "ever-evolving"
- "at the forefront"
- "moving forward"

<a id="2a-content-free-conclusions-and-throat-clearing-phrases"></a>
## 2a. 無實質內容的結論與清喉嚨式贅語

這些片語通常未增加任何資訊，或只是重複周圍結構已具備的功能。請將其刪除或改寫為直接的主張。

| Avoid | Prefer |
|---|---|
| in conclusion, / to conclude, | (delete — the sentence itself should be the conclusion) |
| in summary, / to summarise, | (delete or use a structured roadmap heading) |
| as discussed above / as we have seen / as established earlier | (delete; if needed, cite §X) |
| having explored / having considered | (delete or rewrite as a direct claim) |
| with that said / having said that / that being said | however, (or rewrite) |
| to that end / in light of this | (delete or name the specific reason) |
| the field of X has witnessed / has seen rapid growth | quantify: "publications grew from N to M, 20YY-20YY" |
| in the rapidly evolving landscape of X | (delete; usually meaningless) |
| paving the way for | "supports", "motivates", "suggests" |
| shedding light on | "shows", "indicates", "reveals" |
| this study aims to / sets out to / seeks to / endeavours to | "we test whether", "we estimate", "we show" |
| at the heart of / lies at the core of | "central to" (and only when justified) |

<a id="3-weak-demonstratives"></a>
## 3. 弱指涉詞

標記缺乏明確主詞的開頭，例如：

- "This ensures..."
- "This enables..."
- "This allows..."

除非前一句已使其毫無疑義，否則請將 "this" 替換為實際的先行詞。

<a id="4-sentence-starters"></a>
## 4. 句首詞

通常應避免：

- "Furthermore,"
- "Moreover,"
- "Additionally,"
- "Building on..."
- "Together,"
- 重複的 "By [verb]-ing, we..."

取決於風格的句首詞（如 "Although"、"Yet"、"By contrast"、"Therefore"
及 "Thus"）應遵循期刊與指導教授的偏好。

<a id="5-structural-patterns"></a>
## 5. 結構模式

<a id="long-dash-overuse"></a>
### 破折號過度使用

某些期刊允許使用破折號，而某些指導教授則不喜歡。通用的規則是避免過度使用：單一段落中出現超過兩個破折號通常代表草率或陳腔濫調的散文。請遵循進行中的專案寫作契約。

當專案提供了經語料庫校準的破折號額度時，請使用該基準，而非全領域的平均值。在推導此類基準時，優先參考目標作者自身的第一作者與通訊作者論文。

<a id="adjective-stacks"></a>
### 形容詞堆疊

避免如 "comprehensive robust multi-scale framework" 般堆疊名詞。請使用單一形容詞與精確的片語。

<a id="colon-lists-inside-prose"></a>
### 散文內部的冒號列舉

避免 "Three factors: (a)..."。請將清單融入句子中，或使用正式的列表結構。

<a id="repetitive-openings"></a>
### 重複開頭

連續三個以 "The" 或 "This" 開頭的句子應予以修訂，除非該重複是刻意為之且意義明確。

<a id="participial-chains"></a>
### 分詞片語鏈

避免使用如 "Building..., integrating..., and leveraging..." 的段落開頭。
請使用直接的主張。

<a id="6-overclaim-language"></a>
## 6. 過度主張語言

對於推論得出的發現，應避免：

| Avoid | Prefer |
|---|---|
| confirms | is consistent with |
| proves | suggests |
| demonstrates | indicates |
| determines | shapes |
| controls | influences |
| ensures | tends to |
| eliminates | reduces |
| drives | contributes to |
| explains | may explain, is consistent with |

僅在有統計證據時才使用 "significant"。

報告框架豁免。"the results show/showed that ..."、「the [model]
results showed that ...", and "results suggest/indicate that ...」允許作為引介模型或實驗產出的中性框架。該框架本身並非過度主張；語氣審慎的保留說法應放在數值之後的解讀上。
請勿將此框架自動重新對應為 "is consistent with."。請套用 [universal-integrity.md](universal-integrity.md) 中的主張處理範圍檢查。

<a id="7-mechanistic-trigger-phrases"></a>
## 7. 機制誘發片語

除非方法明確支持，否則這些片語通常會招致審稿人的質疑：

| Trigger phrase | Safer replacement |
|---|---|
| preferentially selected | more likely to |
| systematic bias | average difference of X |
| filter tightens | share changes from A to B |
| removed from the denominator | no longer included in the group |
| residual group | remaining group meeting criterion X |
| isolates the effect | focuses on, conditions on |
| hard-coded | specified in Methods |
| explains away | accounts for X of the gap |
| must, necessarily, invariably | tends to, on average, in N cases |

<a id="8-detection-heuristic"></a>
## 8. 偵測啟發法

針對任何有疑慮的句子，請思考：

1. 具該領域專業知識的博士生會這樣寫嗎？
2. 刪除該句子是否會損失資訊？
3. 單一名詞前是否堆疊了過多形容詞？
4. 該句子是否在需要技術術語之處使用了隱喻？
5. 每個指涉詞是否有明確的先行詞？
