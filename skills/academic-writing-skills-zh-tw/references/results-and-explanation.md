## 處理範圍與證據排序

在規劃、起草或實質性審查各項發現時請使用本指引，包括在其他標題下的綜合發現、命題及基準評估。保留運作良好的已提交或經指導教授編輯之文本；修復缺失的功能，而非全盤重寫該節。

一旦讀者知曉所比較的事物，即可圍繞著「**發現 → 必要證據 → 意涵 → 實質性回答**」來組織結果單元。如下文所述，首先補足任何缺失的圖表導引說明。這些是資訊功能，而非四個強制的句子。陳述發現了什麼、指明比較對象、報告足以做出評判的證據，並說明該結果就研究問題而言確立了什麼。將可重現的流程置於方法（Methods）中；僅在理解某項發現需要設計細節時簡要回顧。

在安排支持性數值之前，先選定主要模式或比較。不要機械性地列舉變數、組別或子圖：讀者應當明瞭這些數值論證了什麼，而非必須從數值清單中去推導發現。當變數、子圖或時間順序有助於推進清晰的分析論點時，採用此等順序是合適的。研究發現可能是異質的、具不確定性的，或是未顯示明顯變化；「模式優先」的寫作方式並不代表獲准提出更強烈的主張或捏造機制。

在段落或小節完成其分析論點之處給出 “so what”。它可以指明路徑對比、取捨權衡、邊界、獲得支持的關係或負面發現。切勿僅以統計數據、“These results answer SQ1,” 或泛泛的重要性宣告作為結尾。暫時移除研究問題標籤與導言式的後設話語：該回答本身仍必須易於理解。帶編號的 SQ/RQ 標籤是可選的導航工具，而非證據。

以連貫的結果單元建立該項解釋，而非將所有意涵推遲到最後包含一切的總結句。數個數值可以支持同一項發現：將它們保留在一起，說明該項比較確立了什麼，然後讓下一個單元對其進行深化、對比或限定。例如，在轉向離散度之前先確立分數水準所代表的意涵，並在得出群體層級的結論之前區分個別關係與整體模型比較。所需的過渡橋樑是分析上的關聯，而非另一個連接詞。不要在每個數字後面都插入解釋、不要在每個段落都重複研究問題，也不要拆分運作良好的多數值發現。

對於跨多個分析層次展開的比較，應指明當前層次貢獻了什麼，而不僅是它出現在序列中的何處。在起草前，先說明比較了哪個層面、其證據能確立什麼，以及後續的比較將增加什麼或必須兼顧什麼。起草後，在移除研究問題標籤與套話框架的情況下，直接從正文中梳理出這些關係。在條列結果後加上 "this is the first level" 或 "this answers RQ2" 並不能提供所缺失的關聯。當數個數值支持同一項發現時，應將其置於同一處；不要規定每個段落都必須有目的句或論述路徑圖。

區分當前層次的發現與其對後續解釋的相關性。例如，不同的測量輸入可為分數比較提供脈絡背景，但這並不代表它能解釋每項分數差異，也不代表它禁止了後續的關係比較。僅陳述所提供之設計所能支持的結果。將證據及其解釋放在一起；將技術性表格指引置於有助於閱讀而非打斷該單元之處。當此特定執行缺口再次出現時，請使用 [evidence-context case 11](evidence-context-cases.md#11-comparison-contribution-is-not-a-sequence-label)；運作良好的正文則應維持不變。

<a id="visuals-and-substantive-answers"></a>
## 視覺圖表與實質性回答

每張圖表偏好設定一個主要問題或分析目的。這並非強制的「一圖一問」比例：相關的子圖可以支持一項漸進累積的比較，多張視覺圖表也可以共同回答一個問題。當不同子圖群組的相異目的模糊了論點時，應將其拆分；切勿僅為了符合比例而增加圖表數量。

在呈現圖表之前，若語境需要，應先提供研究問題或比較。在提供必要證據之後，於單元的自然邊界處陳述答案。不要在每個子圖周圍都重複完整的預覽與綜合論述。將數值追溯至實際的輸出與圖表展示，核對基準線、組別、時間、單位、分母、聚合方式、摘要統計量、不確定性與四捨五入。顯示的四捨五入端點毋需完全精確重現由未四捨五入數值計算出的百分比；應核實底層計算，並在四捨五入具有實質影響時予以說明，而非藉由更改數值來強求一致。

<a id="first-and-repeated-display-encounters"></a>
### 圖表的首次出現與再次出現

在首次遇到不熟悉的圖表展示或比較時，在報告數值前，應先簡要告知讀者它展示了什麼證據、比較了哪些實體或條件，以及應注意觀察什麼。對於分佈圖，應區分分數或測量值、母體，以及比較關注的是位置、離散度還是形狀。僅在該項發現需要時才解釋不明顯的編碼方式；將完整的圖例與繪圖流程保留於圖題和方法（Methods）中。若相鄰正文已提供了該導引說明，切勿重複添加。

接著陳述觀察到的模式，以相關數值加以支持，並在段落或小節的自然收尾處解釋其有依據的意涵。單單一句「Figure X presents the results」並不能引導讀者，但當主詞與目的已很明確時，以圖表開頭的句型或動詞 "presents" 本身並非本質上有錯。切勿以純粹的後設話語取代以研究發現為導向的實用開頭。在解釋中，指明是誰的數值在何種層次上變異；如 "less variation in the summaries" 這樣的片語可能會掩蓋人與人之間、地點之間或重複執行之間的變異。精簡行文必須保留該項區分。

對於後續使用相同既定閱讀邏輯的圖表展示，請承接該脈絡，僅介紹新的母體、條件、比較或發現。不要針對每張圖表都重複繪圖教學、圖例或 "we first / we then present" 框架。當數量、分母、母體、編碼方式或不確定性發生變化時，或當該單元必須獨立成篇時，請重新引入其意涵。相同的繪圖類型並不代表估計標的（estimand）相同。請將相同的決策準則套用至表格、地圖、質性圖表與證據綜合分析，而非假定每個結果（Results）章節都包含分佈圖。

針對圖題、註釋、視覺尺寸及同步性檢查，請使用 [figures-tables-and-supplements.md](figures-tables-and-supplements.md)。

<a id="mechanisms-and-logical-flow"></a>
## 機制與邏輯流向

<a id="resultexplanation-continuity"></a>
### 結果與解釋的連貫性

將結果及其解釋視為連貫的正文閱讀，而非各自單獨潤色的句子。在其交界處，指明該解釋所詮釋的具體觀察比較為何，以及該詮釋增加了什麼。一連串正確的短句若在未提供該關聯的情況下改變了主詞、比較、分母或分析層次，讀起來仍可能像是互不連貫的筆記。

以最小的修改修復該關係：指明被解釋的結果、將必要的比較置於其旁、重排前提順序，或在子句的對比、條件或限定本屬於一體時將其合併。不要合併每個短句、不要強加最小句長限制，也不要添加套話連接詞。保留清晰簡短的散文與專業區分；若該關係需要目前無法取得的證據，請說明該限制，而非為了使段落流暢而憑空捏造原因。

例如，若僅給定各組平均值相似且 A 組的人與人之間的變異較小，`The means were similar. A was concentrated. The groups agreed.` 並未能嚴謹穩妥地傳達該項比較。最小修訂是 `The groups had similar mean scores, but responses varied less among people in group A.` 這將所提供的發現連結起來，而未宣稱對等一致或等價。這是一個假設性的說明，並非要把所有結果合併成單一句子的規則。

區分模型或程序規則、觀察到的輸出、由分解法或其他適當分析支持的解釋，以及貌似合理但未經檢驗的詮釋。單憑規則並不能確立為何會出現總體模式。支持現實世界機制的文獻引用，並不能證明該機制在當前數據集或模擬中有所運作。

透過明確的關係將解釋與所報告的模式連結起來。“A therefore B” 要求該連結具備證據支持，而不僅是看似合理的時間或邏輯順序。若解釋尚未經檢驗，在文體將結果（Results）與討論（Discussion）分開的情況下，應對其加以限定，並將延伸詮釋置於討論部分。在結果部分進行簡明的限定說明可以防止誤讀，同時不至於演變成推測性的因果敘事。

不要從群體平均值推論個體變化、不要從多個同時發生的變化中單獨分離出單一原因，也不要將情境模擬機制轉變為實證驗證。指明確實展示出的貢獻，以及提出更強烈主張仍需要的診斷分析。不要僅僅因為正文審查揭示了該缺口就直接去執行該診斷。

<a id="hidden-comparison-checks"></a>
## 隱含比較檢查

在章節收尾處，請使用 [lifecycle-and-routing.md](lifecycle-and-routing.md) 選取適用的問題。不要對每種研究設計都硬套每項數值檢查。

| 內容觸發條件 | 採納該詮釋前應檢查的事項 |
|---|---|
| 變動的群體平均值或軌跡 | 成員異動、遷移、損耗、重新分類或加權是否可能改變其組成成分？在證據允許的情況下，將單位內部變化與組成成分變化區分開來。 |
| 比率、縮減或正規化 | 是否指明了參考組／參考情境／參考時間？分子、分母、加權、聚合順序以及初始／當前母體是否清楚？相等的百分比單位可能掩蓋不同的實質意涵。 |
| 排序曲線或分位數差異 | 數值是否在相同機率下、或針對相同觀察／事件進行比較？切勿將各自獨立排序的曲線差異稱為事件配對的給付或處理效應。 |
| 重複試驗、誤差線或區間 | 代表了何種不確定性：隨機試驗、測量、抽樣、參數還是序列？切勿將有條件的模擬變異性轉換為涵蓋所有不確定性。 |
| 空間類別或顏色改變 | 顏色代表的是等級、變化還是聯合類別？類別邊界可能掩蓋微小但非零的變化；顏色改變本身並不能作為新機制或推翻主要結論的證據。 |
| 看似相似的結果 | 相似性僅是描述性的，還是依照明確標準檢驗過等價性／一致性？切勿捏造正式檢定。 |
| 共享量表上不同構念的分數 | 所陳述的基準是否支持對各個分數的詮釋？共通的範圍或中點並不能確立哪個構念更重要、更強烈或更有影響力。在計分意涵明確時，描述性數值可予保留。 |
| 組件檢定後接著提出群體或模型主張 | 證據是否檢驗了確切的對比與層次？各組內部各自的顯著性不能確立組間差異；數個不顯著的組件不能確立整體模型的等價性。保留核心的負面發現，切勿將其提升為等價。 |
| 統計顯著性後接著提出重要性主張 | 實質重要性是否獲得效應量、不確定性、相關基準及研究脈絡的支持？單憑微小的 p 值完全無法提供上述任何支持。 |
| 質性主題或綜合計數 | 計數屬於範例說明、編碼出現次數，還是盛行率估計？保留反例與證據邊界；切勿將出現頻率提升為母體普遍性。 |
| 定理或架構應用 | 結論獲得哪項前提或要求的支持？範例展示並不能確立所有宣稱的邊界條件或廣泛實用性。 |

例如，在變動的鄰里樣本中，認知平均值的下降可能反映了個人數值的降低、成員組成的改變，或兩者皆有。在缺乏追蹤個體單位的證據時，應報告總體下降，而將其具體分解留待未決。這是一個假設性的診斷說明，並非針對任何論文規定的解釋。

<a id="reader-test"></a>
## 讀者檢驗

在視覺圖表呈現為預期尺寸的情況下閱讀該結果單元。讀者是否能解釋比較了什麼、改變了什麼、證據如何支持該解釋，以及該發現為何對研究問題至關重要？若無法，請修復該特定缺失的環節。依序閱讀開頭句與結尾句以檢驗漸進累積的邏輯，而非檢驗是否符合套話句型。回報無法取得的證據，而非認證未看過的產出。
