<a id="scope-and-reader-functions"></a>
## 處理範圍與讀者功能

Methods 說明本研究如何產生回答問題所需的證據，並提供足夠的細節以理解並重現重大的程序。請使用下列功能規劃所要求的單元，而非將其視為五個強制的子章節。應使用 [study-design-adapters.md](study-design-adapters.md) 將其調整適配至實際的研究設計。

| 讀者功能 | 相關時應提供的資訊 |
|---|---|
| 理解整體研究取徑 | 研究的單元、擬進行的比較，以及主要步驟如何與研究目的連結。 |
| 理解輸入資料 | 資料來源、選取、測量，以及實質轉換或指派。 |
| 跟循程序步驟 | 輸入、操作、產出以及相關的先後順序或相依性；符號使用前應先定義。 |
| 理解重大選擇 | 何者來自證據、研究者做了何種選擇、為何該選擇是合適的，以及何者仍屬假設。 |
| 理解評估與設計 | 與研究設計及主張相關的實際比較基準線、診斷、校正、驗證、不確定性或敏感度分析程序。 |

撰寫程序性段落時，開頭應先明確說明其角色，接著解釋其如何運作以及任何重大的基本原理。應在相依操作之前先引入前置條件，而非讓讀者從後續文本中拼湊其先後順序。切勿對每個例行步驟都加入冗長的辯護。正文必須保留核心邏輯；補充資料可收納詳細設定或推導，但不能取代理解該方法所需的必要說明。

<a id="separate-origin-application-and-evaluation"></a>
## 區分來源、應用與評估

有來源出處的參數並不等於毫無假設的參數。應檢核三個獨立的問題：

1. **來源：** 該數值、分布、關聯或規則源自何處？
2. **應用：** 它在此處如何被使用，以及有哪些額外選擇使該使用成為可能？
3. **評估：** 有何證據評估了該使用，且該項評估實際上確立了什麼？

這些類別可共存於單一設定中。例如，某個數值可以是在資料上配適擬合、在某個假設下轉移套用至另一個母體，並在敏感度實驗中進行檢驗，但未經外部驗證。

| 來源 | 準確回報 | 切勿暗示 |
|---|---|---|
| 觀察或測量所得 | 資料來源、相關單位，以及其使用所需的任何測量或前處理。 | 合成指派是觀察到的住戶或現地記錄。 |
| 實證估計或配適所得 | 提供該數值或關聯的資料與估計程序。 | 橫斷面配適可識別時間動態或因果機制。 |
| 校正所得 | 所調整的參數、校正目標或標的、資料與程序。 | 配適某一目標即可驗證每個模型組件或獨立預測。 |
| 採納自既有研究、手冊或預設值 | 該來源提供的確切設定及其與當前使用的相關性。 | 定性論理可提供具體數值，或預設值是在現地估計所得。 |
| 作者假設或簡化 | 所選規則或數值，以及簡要且針對本研究的論理依據。 | 僅因相關概念有文獻引用即代表其已獲實證識別。 |
| 情境或敏感度設定 | 實驗變更、比較基準線與目的。 | 測試的範圍是估計的信賴區間，或穩健性可證明規則正確。 |

應用假設可能涉及尺度、母體或時間的移轉套用、指派通用數值、將變數固定、獨立性、操作門檻或更新規則的形式。應指明實際的假設，而非將每項設定都稱為 “data-based” 或 “assumed.”。未知的來源在經過檢核前仍屬於未核實；切勿擅自將其歸類為作者假設。

驗證各文獻引用所支持的項目：數據、方程式、定性論理、制度背景或評估主張。支持某單一角色的文獻引用並不會自動支持其他角色。應明確區分程式碼驗證、校正、實證驗證與敏感度分析。模型中所呈現的機制，並不能作為該機制導致了所觀察到真實世界結果的證據。

<a id="explain-consequential-choices"></a>
## 說明重大選擇

對於攸關詮釋的重要設定，應保留這份精簡紀錄的相關部分：**所規定的項目**（在適用處包含數值與單位）、**其來源**、**其如何被應用**、**其餘的假設與論理依據**，以及**有何評估予以支持**。當有多個設定需要比較時，請使用簡明散文或表格；無須為每個例行參數都建立流水帳。

在首次相關操作使用處，即應說明重大假設。陳述促成該假設的實際研究目的、證據限制或模型簡化。“This is an assumption” 能標明狀態，但並未回答為何做出該選擇。除非已有確切根據，否則切勿捏造論理依據或將缺乏資料說成是原因。相關的研究限制界定了詮釋範圍；但這不能成為在 Methods 中將操作規則交代不清的藉口。

在稽核既有文本時，首先應比對其主張與現有來源及實作。修復誇大陳述或缺失的區分，但切勿暗中更改設定。若無法取得必要證據，應標記確切的未知事項並限制該主張。編輯請求並未授權進行新的校正、敏感度執行或替換參數數值。

<a id="hypothetical-examples"></a>
## 假設性範例

以下為教學用的假設性範例，並非對任何稿件的已驗證描述。其中不含可重複使用的數值設定或文獻引用。應借鑒其區分方式，而非其科學主張；僅在相應程序已確認時，方可使用範例措辭。

<a id="a-a-fitted-starting-distribution-and-an-assumed-time-rule"></a>
### A. 配適所得的初始分布與假設的時間規則

假設調查資料提供了某項行為特徵的初始分布，但模型在時間推移過程中將該特徵固定不變。

- **源自證據的部分：** 配適擬合的初始分布及其參數。
- **假設的部分：** 時間上的恆常性。若將其獨立指派給各代理人，這是一項單獨的選擇，而非配適分布所得的必然結果。
- **可能的措辭：** “The initial trait distribution is fitted to survey responses. We hold the trait fixed during the simulation because the survey does not observe within-person changes over time.” 僅在調查與建模論理確實予以支持時，該原因方可使用。

切勿將其壓縮為 “the behavioral dynamics are calibrated using survey data.”。該項調查可能支持初始化，但並未識別時間動態。同樣地，手冊可提供初始數值，但將該數值套用於模型中的每個住戶依然屬於簡化處理。

<a id="b-institutional-background-does-not-estimate-an-adoption-threshold"></a>
### B. 制度背景並非估計採納門檻的根據

假設現實世界的保險規則為兩個群組提供了採用不同採納門檻的動機，但具體的數值區間是由研究者所選定。

- **有來源支持的部分：** 相關的制度區分，包括該規則適用的條件。
- **假設的部分：** 所選定的數值區間及其作為代理變數的使用，而非明確執行該機構的制度規則。
- **可能的措辭：** “The institutional distinction motivates separate adoption thresholds for the two groups. The intervals are model assumptions; the cited policy does not estimate their values.” 若已知選定該區間的實際原因，應予說明。

單純引用該項政策並無法支持 “thresholds estimated from the policy.”。任何敏感度評估皆應另行回報；在測試區間內產出未變更，並不能驗證原本的區間。

<a id="c-a-published-community-level-formulation-applied-to-individuals"></a>
### C. 將已發表的社區層級公式套用於個人

假設模型改編了已發表的社區層級記憶公式，利用當地總體損失來更新個人認知。

- **有來源支持的部分：** 其所陳述分析層級上的原始公式。
- **假設的部分：** 個人層級的套用，以及將總體損失作為訊號（反映出除了個人損害之外，亦可能受到社區洪災經驗的影響）。
- **可能的措辭：** “We adapt the community-level formulation to individual perception and use local aggregate losses as the update signal. This assumes that perception can respond to community flood experiences, not only personal damage.” 若有佐證，應將該論理依據的支持文獻與公式來源分開引用。

除非有證據確立該主張，否則切勿將此移轉套用描述為經實證驗證的個人更新。共享總體訊號亦不代表已對住戶互動、資訊傳播或社群網路學習進行了明確建模。

<a id="d-qualitative-sampling-and-an-unsupported-coverage-claim"></a>
### D. 質性抽樣與缺乏佐證的涵蓋範圍主張

假設訪談採用立意抽樣與反身性主題分析。招募程序與編碼方法皆可詳實記錄，但這並未確立母體盛行率或飽和度。應說明實際的選樣論理與分析流程；切勿僅因 “representative” 或 “saturation achieved” 這些詞彙常出現在 Methods 中就逕行添加。若經確認且相關，應指出研究者立場與反例處理方式。

<a id="e-a-theoretical-premise-and-a-proved-conclusion"></a>
### E. 理論前提與經證明的結論

假設針對具有非負容量的圖推導出一個定理。應將陳述的前提與透過證明所確立的結論明確區分開來。切勿將該前提描述為經實證校正、切勿強求實驗資料集，亦切勿在缺乏支撐論證的情況下將結論延伸至負容量。此處的可重現性是指具備可供檢視的推導過程與定義，並不一定代表需要隨機執行。

<a id="design-dependent-hidden-failure-checks"></a>
## 視研究設計而定的潛在失效檢核

在程序與來源出處皆清楚易懂後，請檢查下列相關的比較與相依關係。這些是診斷性問題，並非要求在每種研究設計中都加入所有分析、假設表格或研究限制。

| 潛在的隱含問題 | 在接受該詮釋前應先確立的事項 |
|---|---|
| 群組比較同時改變了數項初始條件 | 哪些屬性或條件存在差異，以及該設計實際隔離了何者？描述性的群組比較不必然要隔離特定路徑，但切勿將其呈現為因果效應。 |
| 摘要統計掩蓋了運算順序 | 比率是在聚合之前還是之後計算？使用了哪些權重？分母是初始值還是當前值？單元比率的平均值與總數的比率，未必回答同一個問題。 |
| 變動的群組平均數看似個體的變動 | 觀察對象是否追蹤相同的單元，抑或搬遷、退出或重新分類會改變成員組成？在現有證據允許的範圍內，應區分單元內部的變動與組成的變動。 |
| 重複執行看似額外的實證觀察 | 重複執行是相同輸入的隨機實現、新的觀察值，還是獨立的實驗單元？說明所回報的變異性代表何者，以及其未涵蓋哪些不確定性。 |
| 評估與輸入資料或配適目標重疊 | 哪些資料與轉換在校正與評估中被重複使用？揭露該項相依性，並使評估主張與實際證據相符；獨立的外部驗證並非每項研究的強制要求。 |
| 某項解釋僅僅是重複了程式設定的規則 | 除了規則本身之外，有何產出或診斷可支持該項解釋？如 [universal-integrity.md](universal-integrity.md) 所述，應將所呈現的機制、觀察到的模式、經檢驗的解釋與未經檢驗的詮釋明確分開。 |

缺乏支持更強烈詮釋的證據，並不必然代表該方法有誤。應適時限縮主張、指明未解決的區分，或在適當情況下提出具針對性的診斷方案。切勿僅為了完成寫作檢核，就聲稱已執行該項診斷，或在未獲必要授權的情況下逕行執行。

<a id="scope-aware-revision-checks"></a>
## 具備處理範圍意識的修訂檢核

對於單一句子或段落，檢核其切實提及的重大設定以及相鄰文本中可用的前置條件。對於 Methods 的小節，追溯其輸入、程序、產出與來源出處。對於章節或稿件審查，額外比對相關的參數表、方程式、實作證據、補充資料，以及校正或驗證的主張。切勿將所有可能的檢核套用於每次局部編輯。

當已獲接受或經指導教授編修的基準版本已具備這些功能時，應予保留。僅更正缺失的區分、缺乏佐證的歸因、重大的疏漏或受影響的銜接轉折。使用 [lifecycle-and-routing.md](lifecycle-and-routing.md) 進行影響掃描；檢核某項相依關係並不會擴大寫入授權。若無設定變更，切勿暗示模型已重新執行或重新完成驗證。

對於跨章節的規劃或審查，請使用 [introduction-and-study-context.md](introduction-and-study-context.md) 中的交接檢核。局部的程序或文法編輯不需要進行該項完整的跨章節審查。
