# Conditional Project Precedents

Load this file only after the user or manuscript establishes the exact project. Treat every item as prior-review context requiring confirmation against current project state.

## Wenyu-Type Flood Adaptation Projects

- Distinguish social-vulnerability group labels from housing-tenure categories; require an explicit mapping only if the analysis connects them.
- Check whether the result demonstrates something beyond a direct consequence of input values or model structure.
- Verify sensitivity symbols against the current Methods and analysis outputs.

Do not import sample sizes, funding, model versions, research questions, author roles, or preferred terms from another Wenyu manuscript.

## Madan-Type Water-Policy ABM Projects

- Verify current scenario names and targets from project sources before enforcing labels.
- Check what learning adds relative to the current baseline and whether social diffusion and economic compliance are separately represented.
- Treat previous political-feasibility comments as queries requiring current jurisdictional evidence.

## YLin-Type Framework Projects

- Check whether bidirectional feedback, real-time exchange, modularity, and reuse are distinguished.
- Verify the current competitor literature rather than requiring a fixed list of approaches.

## Husamettin-Type Hydrodynamic Projects

- Recheck study-context versus model-setup functions, coupling definitions, model counts, event inclusion, figures, and readability.
- Confirm current model capabilities before challenging a caption.

## Shrouq-Type Sensor or Surrogate Projects

- Verify the source and target setting before judging transfer-learning terminology.
- Check sensor configurations, temporal resolution, split design, and gap claims against current evidence.

## Historical Review Patterns

Past direct comments, figure redesigns, vocabulary choices, and comment-count trajectories may calibrate tone or reveal recurring failure modes. They are not current instructions unless preserved in the issue or decision ledger.
